サイトを公開する

  1. 1アドレスを選ぶ

    ドメインをサイトに向ける

    ドメインを購入したサービスの管理画面で DNS 設定を開き、下のレコードを追加してください。同じ名前の古いレコードは削除します。

    種類名前値

    DNS の反映には数分から24時間かかります。正しく設定されると、約1時間で GitHub が HTTPS(鍵マーク)を有効にします。

  2. 2GitHubと連携

    サイトはあなた自身のGitHubアカウントに無料で保存されます。持ち主はあなたで、Kingpesがサイトやデータを預かることはありません。

    GitHub連携は現在準備中です。下書きはこのブラウザに保存されています。それまでの間、サイトをダウンロードできます。
