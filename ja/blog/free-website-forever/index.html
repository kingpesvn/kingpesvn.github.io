「無料でホームページ」とうたっていても、14日後にカードを求められたり、サイトに広告が入ったりすることがよくあります。小さなお店に必要なのは、期限を気にせず動き続けるサイトです。この記事では、ずっと無料のホームページを持つ方法を解説します。無料体験と本当の無料の違い、登録前に確かめたいこと、そして家具店と賃貸管理会社の2つの新しいテンプレートを例に紹介します。

1. 「無料体験」と「ずっと無料」の違い

「無料」には3種類あります。無料体験は7〜14日間すべての機能が使え、終わると有料になるかサイトが止まります。制限付きの無料プランはずっと使えますが、サービスの広告、長いサブドメイン、使えない販売機能がつきものです。本当の無料は期限も広告もありません。

無料体験には必ず終わりの日があります。その後サイトがどうなるかを確かめましょう。写真：Amitbalani（CC0）

2つ目はフリーミアムと呼ばれる仕組みで、無料版は慣れるため、商売に十分なのは有料版です。各サービスの条件はよく変わります。この記事の内容は執筆時点（2026年11月）のものです。

2. 「無料で登録」を押す前の4つの質問

商品を入力し始める前に、料金ページで次の4つを確認しましょう。

  • クレジットカードの入力が必要？ カードを登録すると、多くの場合は自動更新で課金されます。
  • 無料体験が終わったらサイトはどうなる？ 止まる、消える、広告付きプランに変わる？
  • 無料プランにサービス名や広告が出る？ お客様の目にも入ります。
  • サイトを持ち出せる？ 書き出せないなら、そのサービスから離れられません。

どれか1つでも引っかかるなら、何時間も入力する前に別の方法を選びましょう。

3. よくある隠れた費用

基本プランが安くても、追加費用で合計はふくらみがちです。有料テーマ、予約・フォーム・地図などの月額アプリ、注文ごとの決済手数料、独自ドメインのメール、そして1年目より高い2年目以降の更新料などです。

毎月の小さな費用も12か月分足すと、サイトの本当のコストが見えてきます。写真：stevepb（CC0）

詳しくはネットショップのホームページはいくらかかる？をご覧ください。ずっと無料のサイトなら、料金表、予約、フォームはテンプレートに入っているので、追加で買う必要はありません。

4. 静的サイトが長く無料でいられる理由

静的サイトは出来上がった HTML ファイルの集まりで、一日中動くサーバーもデータベースも要りません。GitHub Pages はこの種のサイトを無料で公開でき、容量は約1GB、転送量は月100GB程度まで。小さなお店には十分すぎる量です。

静的サイトはただのファイル。月額のサーバーがないので、期限切れになるプランもありません。写真：Scott Webb（CC0）

Kingpes のテンプレートはこの仕組みで作られています。絞り込み、料金計算、日付の確認といった「動く」部分はお客様のブラウザで動くため、やはりサーバーは不要です。サイト全体を .zip でダウンロードして保管したり、移したりもできます。

5. お金をかける価値があるのは独自ドメインだけ

無料のサイトは your-name.github.io のようなアドレスになります。使えますが、yourstore.com のような独自ドメインのほうが覚えやすく、名刺に載せても信頼感があります。年に一度払うこの費用だけが、かける価値のあるものです。

買う前に無料ドメインはお店に向いている？を読んで、1年で取り上げられる「無料」ドメインを避けましょう。ドメインを買ったらサイトにつなぐだけで、公開は無料のままです。

6. 例：今週の2つのテンプレート

家具店のテンプレートには、置き場所とドアのサイズを入れて家具が入るか確かめる「置けるか確認」、配送と組み立ての合計目安、無料の生地サンプルがあります。すべて静的サイトで動き、有料アプリは要りません。

家具店には写真や商品ページがたくさん必要ですが、静的サイトなら無料で公開できます。写真：Justin Schüler（CC0）

賃貸管理会社のテンプレートには、「すぐ入居可」を自動で表示する物件一覧、オーナー向けの料金計算、修理依頼フォームがあります。詳しくは賃貸管理会社のホームページの記事をどうぞ。

よくある質問

ずっと無料のホームページは本当にありますか？

あります。静的サイトを GitHub Pages のように長く無料で使える場所で公開すれば、月額で借りるサーバーがないので、期限切れになるプランもありません。費用がかかるのは独自ドメインを使う場合だけです。

ホームページ作成サービスの無料プランで十分ですか？

試すには十分ですが、多くはサービスの広告が入り、長いサブドメインになり、ネット販売の機能が使えません。条件はよく変わるので、料金ページをよく読んでから選びましょう。

あとで別の場所に移したくなったら？

Kingpes のテンプレートなら、サイト全体を .zip ファイルでダウンロードできます。普通の HTML ファイルなので、どのサーバーでも公開できます。

無料のホームページにクレジットカードは必要？

不要です。本当に無料ならカード番号は求められません。「無料」なのにカード入力を求められたら、自動更新されて課金される無料体験の可能性が高いです。
