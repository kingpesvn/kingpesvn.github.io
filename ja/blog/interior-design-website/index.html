リフォーム・内装会社のホームページに必要な7つの項目

リフォーム・内装・家具工房のホームページに何を載せる？施工事例、サービスと流れ、㎡単価の目安、素材、工房と職人、お客様の声、現地調査の予約フォームの7項目。

内装やリフォームを頼む会社を探す人は、電話する前にとても慎重に調べます。これまでの施工はどうか、費用はいくらくらいか、工期は守られるか。よいリフォーム・内装のホームページはこうした疑問に先に答え、最初の電話が本当に関心のあるお客様から来るようにしてくれます。この記事では、家具工房、設計施工会社、リフォーム業者、家具店に向けて、載せるべき7つの項目を紹介します。

1. ビフォーアフター付きの施工事例

内装の仕事では、施工写真がいちばん強い営業ツールです。お客様は自分の家と似た家がどう変わったのかを見たいのです。

工事前の現況写真があると、どれだけ部屋が変わったかが一目でわかります。写真：rawpixel（CC0）。

  • 種類別（マンション、戸建て、店舗、オフィス、カフェ）や部屋別（リビング、キッチン、寝室）に事例を分けます。
  • 各事例に工事前・工事中・完成後の写真、広さ、地域、工期を載せます。
  • お客様の要望と解決方法を1〜2文で。たとえば「間口3.5mの狭小住宅で、収納を増やしたい」。
  • きれいでも実際には施工していない3Dパースより、スマホ写真でも自社の本物の写真を優先しましょう。

撮影に慣れていない方は、スマホで商品写真を撮るコツもご覧ください。光と角度のコツは施工写真にも使えます。

2. サービス内容と工事の流れ

お客様は何から始めればいいかわからないことが多いもの。サービスと流れがはっきりしたページがあると安心してもらえます。

図面と見積りの段階を見せると、なぜ先に現地調査が必要なのかが伝わります。写真：rawpixel（CC0）。

  • **サービス：**設計、設計施工一括、オーダー家具・造作家具、修繕・リフォーム、家具の販売のみ。
  • 工事の流れを段階で。たとえば：現地調査 → プラン提案と見積り → 契約 → 工房で製作 → 取り付け → 引き渡しと保証。
  • 各段階に目安の期間と、お客様に準備してほしいことを書きます。

3. わかりやすい料金の目安

多くのお客様の最初の質問は「全部でいくらかかるの？」です。料金がまったくないと、ページを閉じてほかを探す人も少なくありません。正確な見積りでなくても、目安の価格帯があれば十分です。

  • ㎡単価（坪単価）：マンションや戸建ての設計、設計施工一括。
  • 項目別：キッチン収納は1mあたり、クローゼットは㎡あたり、ベッド、テレビボード。
  • プラン別：ベーシック、スタンダード、プレミアム。どの素材が違うのかを明記します。

**「正式なお見積りは現地調査後」**の一文と、料金に含まれるもの（運搬、取り付け、保証）を添えましょう。最初の電話での値引き交渉や誤解が減ります。

4. 素材と仕上げのサンプル

同じキッチン収納でも、素材によって価格は何倍も変わります。素材の説明があれば、価格差の理由がわかり、予算に合わせて選べます。

  • 使っている木材とボード：無垢材、合板、MDF、メラミン化粧板、ポリ合板、アクリル。それぞれ一文で、向いている場所と長所・短所を。
  • 化粧板、天板、取っ手の実物サンプルを撮った色と表面の写真。
  • 金物類：丁番、スライドレール、照明、キッチン天板。

完成したキッチンの写真で、素材を組み合わせた雰囲気をイメージしてもらえます。写真：rawpixel（CC0）。

5. 工房・職人と保証

お客様がいちばん恐れるのは、工事が途中で止まる、工期が遅れる、不具合を誰も直してくれないこと。実在していて長く続けている会社だと示しましょう。

本物の工房の写真で、家具がどこで誰に作られるのかが伝わります。写真：rawpixel（CC0）。

  • 製作工房、機械、資材置き場、作業中の職人の写真（顔を出したくない職人は後ろ姿や遠くから）。
  • 創業年数、施工実績の件数（本当の数字だけ）。
  • わかりやすい保証内容：期間、対象部分、連絡方法。
  • 建設業許可や登録番号、工房またはショールームの住所。

6. お客様の声

あなたが手がけた家に住むお客様のひとことは、どんな広告よりも説得力があります。

  • 3〜6件の声を、お名前（またはイニシャル）、工事の種類、地域とともに。
  • できれば、対応する施工事例のすぐ下に置きます。
  • Googleマップの口コミへのリンクも。Googleマップにお店を登録する方法を見て、お客様に見つけてもらい、口コミを書いてもらいましょう。

7. 現地調査の予約フォーム、電話ボタン、地図

最後に、いちばん簡単に連絡できるようにします。

  • 現地調査の予約フォーム：お名前、電話番号、工事場所、建物の種類、広さ、ご予算、希望日。依頼はメール、LINE、Googleスプレッドシートに直接届くように。
  • スマホでは電話ボタンとLINEボタンを常に表示。
  • ショールームや工房の住所、営業時間、地図、対応エリア。

Googleのビジネスプロフィールのガイドによると、正確で充実した情報は、近くで検索されたときに表示されやすくなります。ホームページとGoogleマップの店名・住所・電話番号はそろえましょう。

まだホームページがない方は、無料でホームページ作成する方法を見るか、無料ホームページテンプレートからデザインを選び、会社名、施工写真、料金表を替えれば、約5分で公開できます。

よくある質問

リフォーム会社のホームページに料金は載せるべき？

目安の料金を載せましょう。たとえば㎡単価（または坪単価）や、リビング・キッチン・寝室などのパック料金に「正式なお見積りは現地調査後」と添えます。価格帯がわかればお客様は電話の前に合うかどうか判断でき、料金だけの問い合わせも減ります。

きれいな施工写真がまだないときは？

直近3〜5件の現場をスマホで、昼間の明るい時間に撮るところから始めましょう。工事中の写真も数枚加えます。自社の本物の写真は、ネットの素材写真より信頼されます。

ホームページでGoogle検索から見つけてもらえる？

各ページにサービス内容と対応エリアがはっきりわかる文章があれば可能です。たとえば「世田谷区のマンションリフォーム」など。Googleマップのビジネスプロフィールと組み合わせると、近くのお客様に見つけてもらいやすくなります。

依頼はフォームと電話、どちらで受けるべき？

両方用意しましょう。急ぐ方には電話とLINEのボタン、広さや予算、現状の写真を先に送りたい方には現地調査の予約フォーム。フォームなら訪問前に準備ができます。
