独自ドメインの無料ホームページ：費用と設定の4ステップ

独自ドメインの無料ホームページの作り方。無料のままの部分、毎年かかる費用、ドメインの選び方と買い方、4ステップの接続方法を解説します。

「無料ホームページ ドメイン付き」と検索して始めたのに、2年目に高い更新料を請求されて驚く人は少なくありません。実際はもっと単純で、サイトの作成と公開はずっと無料にできますが、ドメインだけは毎年少し費用がかかります。この記事では独自ドメインの無料ホームページの作り方として、無料の部分、ドメインの選び方と買い方、サイトにつなぐ4ステップを説明します。

要点は次の6つです。

  1. 独自ドメインとは何か、なぜ無料にならないか
  2. 無料の部分と有料の部分
  3. 覚えてもらえるドメインの選び方
  4. 購入先と更新料の確認
  5. 4ステップでドメインをつなぐ

1. 独自ドメインとは？なぜ無料にならない？

ドメイン名は、お客さまがサイトを開くために入力するアドレスで、たとえば saltlinefish.com です。住所のようなもので、建物（サイト）はどこにあっても、名刺や袋、看板に印刷して覚えてもらうのはこのアドレスです。

ドメインは国際的・国ごとの登録機関が管理し、1つの名前は期間ごとに1人の持ち主しか持てません。そのため登録料と毎年の更新料が必要です。「ずっと無料のドメイン」をうたうサービスは、shop.platform.com のようなサブドメインか、初年度だけ無料のことがほとんどです。

2. 無料の部分と有料の部分

ホームページは3つの部分からなり、お金がかかるのは1つだけです。

  • サイト作成：テンプレートを使えば無料。文章、価格、写真を入れ替えるだけです。
  • サーバー（ホスティング）：静的サイトならGitHub Pagesで無料、HTTPS付き。無料ホスティングも参考にしてください。
  • 独自ドメイン：登録業者に毎年支払います。

独自ドメインがなくても、your-name.github.io のようなアドレスでサイトは動きます。まずはこの形で始めて数週間試し、店名が決まってからドメインを買う方法もあります。

3. 覚えてもらえるドメインの選び方

よいドメインは、一度聞いただけで正しく入力できるものです。

  • 短く、できればハイフンなし：aobara.com は aobara-shop-24h.com より覚えやすい。
  • 看板やSNSの名前と同じか近いものに。
  • 人に読み上げてみて「どう書くの？」と聞かれたら変える。
  • お客さまに合わせて末尾を選ぶ：国内向けなら .jp、海外にも売るなら .com。

ドメインは番地のようなもの。短くわかりやすく、ひと目で読めることが大切です。写真：Daniel von Appen（CC0）

空いているかどうかは登録業者のサイトですぐ確認できます。希望の名前が使われていたら、数字を足すより地域名や業種を足しましょう。

4. 購入先と更新料の確認

ドメインは認定された登録業者から買います。.com は年に1,500〜3,000円程度、.jp はやや高めです。料金は業者や時期で変わり、この記事の情報は執筆時点（2026年11月）のものです。

ドメインは年単位の契約。初年度の割引価格だけでなく、2年目以降の更新料を確認しましょう。写真：Brooke Lark（CC0）

支払う前に、2年目の更新料、他社へ移すときの手数料、所有者情報の公開代行の有無を確認しましょう。サーバーがすでに無料なら、ドメインとサーバーのセット契約は不要です。「セットの無料ドメイン」の注意点は無料ドメインはお店に向いている？で解説しています。

5. 4ステップでドメインをつなぐ

GitHub Pagesのサイトとドメインがそろえば、つなぐ作業は10分ほどです。

  1. GitHubにドメインを登録：サイトのリポジトリで Settings → Pages を開き、Custom domain に入力します。
  2. 登録業者でDNSを設定：ルートドメインをGitHub Pagesに向けるAレコードを4つ、www を your-name.github.io に向けるCNAMEを1つ追加します。
  3. 反映を待つ：通常は数分から数時間です。
  4. Enforce HTTPSをオン：GitHubが無料の証明書を発行し、ブラウザに鍵マークが表示されます。

入力するIPアドレスはGitHub Pagesのドキュメントに載っています。打ち間違えると Settings 画面にDNSのエラーが出るので、直せば大丈夫です。

6. 例：今週の新しいテンプレート2つ

鮮魚店テンプレートは、米国の港にある魚屋という設定で、「本日の入荷」ボード、旬のカレンダー、重さで計算する注文表があります。こうしたお店は氷を入れる袋や市場の看板にドメインを印刷し、常連さんが翌日分を注文できるようにします。

鮮魚店なら、袋に印刷したドメインがお客さまに再来店してもらういちばんの近道です。写真：paul morris（CC0）

ドッグトレーニングテンプレートには、残席つきの開講日、クラス診断、自動で料金が出る個別レッスンのパックがあります。詳しくはドッグトレーニングのホームページを無料で作るをご覧ください。

ドッグトレーナーは口コミで広がる仕事。言いやすいドメインなら、聞いた人が迷わず見つけられます。写真：Justin Veenema（CC0）

よくある質問

.comドメインを完全に無料で取れますか？

ほぼ無理です。.com、.net、.jpなどは登録料と毎年の更新料がかかります。「ドメイン無料」は初年度だけ、またはサーバー契約とセットのことがほとんどです。

独自ドメインにするとサーバー代がかかりますか？

かかりません。GitHub Pagesに置いた静的サイトは、独自ドメインを付けてもHTTPS証明書を含めて無料です。払うのはドメイン代だけです。

設定してからどれくらいで表示されますか？

通常は数分から数時間、DNSの反映に最大24時間ほどかかることもあります。その間も元のyour-name.github.ioのアドレスは使えます。

更新を忘れたらどうなりますか？

サイト自体はGitHubに残りますが、ドメインがサイトを指さなくなり、お客さまはアクセスできません。自動更新をオンにし、普段見るメールで登録しましょう。
