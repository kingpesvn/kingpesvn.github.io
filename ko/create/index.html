템플릿을 여는 중…

웹사이트 게시하기

  1. 1주소 선택

  2. 2GitHub 연결

    웹사이트는 본인의 GitHub 계정에 무료로 저장됩니다. 소유자는 본인이며 Kingpes는 사이트나 데이터를 보관하지 않습니다.

    GitHub 계정이 있어요
    계정이 없나요? 약 2분이면 무료로 가입할 수 있어요
    1. 1
      GitHub 가입 페이지 열기

      새 탭에서 열립니다. 초안은 이 탭에 그대로 남아 있습니다.

      가입 페이지 열기 ↗
    2. 2
      이메일, 비밀번호, 사용자 이름 입력

      사용자 이름은 사이트 주소(your-account.github.io)가 되니 가게 이름처럼 짧게 정하세요. 사람인지 확인하는 간단한 퍼즐이 나올 수 있습니다.

    3. 3
      이메일 인증

      이메일을 열어 GitHub에서 보낸 코드를 입력하세요. 그다음 이 탭으로 돌아와 "GitHub로 로그인"을 누르세요.

    GitHub 화면은 영어입니다: Username = 사용자 이름 · Password = 비밀번호 · Continue = 계속 · Create account = 계정 만들기.

    GitHub 연결 기능은 마무리 중입니다. 초안은 이 브라우저에 저장되어 있습니다. 그동안 웹사이트를 내려받을 수 있습니다.
