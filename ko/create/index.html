웹사이트 게시하기

  1. 1주소 선택

    도메인을 웹사이트에 연결

    도메인을 구매한 곳의 관리 화면에서 DNS 설정을 열고 아래 레코드를 추가하세요. 같은 이름의 기존 레코드는 삭제합니다.

    유형이름값

    DNS 변경은 몇 분에서 24시간까지 걸릴 수 있습니다. 올바르게 연결되면 약 1시간 안에 GitHub가 HTTPS(자물쇠)를 켭니다.

  2. 2GitHub 연결

    웹사이트는 본인의 GitHub 계정에 무료로 저장됩니다. 소유자는 본인이며 Kingpes는 사이트나 데이터를 보관하지 않습니다.

    GitHub 연결 기능은 마무리 중입니다. 초안은 이 브라우저에 저장되어 있습니다. 그동안 웹사이트를 내려받을 수 있습니다.
