코딩 없이 홈페이지 만들기: 사장님도 5분이면 끝

코딩 없이 홈페이지 만들기 5단계. 템플릿 고르기, 글과 사진, 가격, 주문 받는 방법, 게시까지. 오픈 후 해야 할 일도 정리했어요.

가게 홈페이지가 필요한데 “코딩”, “HTML”, “호스팅”이라는 말만 들어도 부담스러우신가요? 이제는 코딩 없이 홈페이지 만들기가 가능합니다. 템플릿을 고르고 글, 사진, 가격만 바꾼 뒤 게시 버튼을 누르면 돼요. 이 글은 약 5분 걸리는 단계와 오픈 후 할 일을 알려 드립니다.

코딩 없이 홈페이지 만들기 5단계 요약:

  1. 업종에 맞는 템플릿 고르기
  2. 가게 이름, 글, 사진 바꾸기
  3. 상품과 가격 넣기
  4. 주문 받는 방법 연결
  5. 게시하고 링크 공유

1. 업종에 맞는 템플릿 고르기

“코딩 없이”란 HTML, 모바일 화면, 장바구니가 이미 템플릿에 만들어져 있다는 뜻이에요. 할 일은 가게가 파는 방식에 가장 가까운 템플릿을 고르는 것. 업종마다 필요한 기능이 다르니까요.

손님 대부분이 휴대폰으로 보니 작은 화면에서 잘 보이는 템플릿을 고르세요. 사진: Saulo Mohana (CC0).

예를 들어 타이어·휠 가게 템플릿에는 사이즈 검색과 장착 예약이, 이사 업체 템플릿에는 방 개수와 거리로 계산하는 가격 계산기가 들어 있어요. 기능을 직접 생각할 필요가 없습니다.

2. 가게 이름, 글, 사진 바꾸기

“템플릿 사용”을 누르면 편집기가 열립니다. 내용 탭에서 가게 이름, 소개 문구, 대표 사진을 바꾸세요. 무엇을, 어디서, 무엇이 다른지 짧게 쓰면 됩니다.

사진은 휴대폰으로 창가에서 깔끔한 배경에 찍으세요. 예쁘지만 내 가게가 아닌 사진보다 실제 사진 한 장이 더 설득력 있어요.

3. 상품과 가격 넣기

상품 탭에서 이름, 사진, 설명, 가격을 고칩니다. 사이즈나 색상이 여럿이면 선택지를 추가해 각각 가격을 매길 수 있어요. 잠시 품절인 상품은 지우지 말고 숨기세요.

템플릿을 쓰면 가장 오래 걸리는 건 상품 입력, 나머지는 몇 분이면 돼요. 사진: Liilia Moroz (CC0).

팁: 잘 팔리는 5~10개를 먼저 넣고 빨리 게시한 뒤 나머지는 천천히 추가하세요.

4. 주문 받는 방법 연결

연락처 탭에 전화번호, 카카오톡, 주소, 영업시간을 넣습니다. 손님이 주문하면 내용이 적힌 카카오톡이나 WhatsApp 메시지가 열려요. 주문을 표로 모으려면 구글 설문지도 연결하세요.

처음부터 온라인 결제가 필요하진 않아요. 작은 가게 대부분은 확인 전화 후 계좌이체나 현장 결제로 받습니다.

5. 게시하고 링크 공유

사이트 게시를 누르면 HTTPS와 함께 무료로 게시됩니다. 처음엔 무료 주소로 시작하고 나중에 내 도메인을 연결해도 돼요. 무료 도메인, 가게에 써도 될까?를 참고하세요.

링크를 인스타그램·틱톡 프로필, 카카오톡 메시지, 계산대 QR 코드에 두세요. 링크를 알려야 손님이 옵니다.

오픈 후 해야 할 일

매주 10분씩 가격과 사진을 업데이트해 정보를 정확하게 유지하세요. 사진: Simon Hattinga Verschure (CC0).

  • 휴대폰으로 열어 보기: 전화·주문 버튼을 눌러 보고 글자가 잘 보이는지 확인.
  • 지인에게 테스트 주문 부탁: 메시지에 필요한 정보가 다 있는지 확인.
  • 구글 지도에 가게 등록하고 프로필에 사이트 링크 넣기.
  • 꾸준히 업데이트: 오래된 가격, 품절 상품은 신뢰를 떨어뜨려요.

자주 묻는 질문

컴퓨터를 잘 몰라도 할 수 있나요?

휴대폰으로 글을 쓰고 사진을 고를 수 있으면 됩니다. 모바일 화면, 장바구니, 전화 버튼 같은 기술 부분은 템플릿에 들어 있어요.

코딩 없이 만든 사이트는 느리거나 별로인가요?

꼭 그렇지 않아요. 템플릿은 보통 모바일에 맞춰져 빨리 열립니다. 사이트를 망치는 건 흐린 사진과 너무 긴 글이에요.

나중에 가격을 바꾸거나 상품을 추가하려면요?

편집기를 다시 열어 고치고 "사이트 게시"를 한 번 더 누르면 됩니다. 누구에게 부탁할 필요도, 처음부터 다시 만들 필요도 없어요.

언제 개발자를 써야 하나요?

포스와 재고 연동, 회원 가입, 복잡한 결제 같은 맞춤 기능이 필요할 때예요. 막 시작한 작은 가게는 대부분 아직 필요 없어요.
