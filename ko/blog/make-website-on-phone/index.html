휴대폰으로 홈페이지 만들기: 컴퓨터 없이 6단계

휴대폰으로 홈페이지 만들기를 6단계로 정리했어요. 템플릿 고르기, 글 수정, 카메라로 상품 촬영, 연락처 추가, 무료 게시까지.

가게에 컴퓨터는 없지만 손님이 구글에서 우리 가게를 찾았으면 좋겠다면, 휴대폰으로 홈페이지 만들기가 가능합니다. 손님과 메시지를 주고받는 그 휴대폰으로요. 앱 설치도, 코딩도 필요 없고 첫 버전은 10~15분이면 됩니다. 작은 화면에서 빨리 만드는 요령과 함께 단계별로 안내합니다.

휴대폰으로 홈페이지 만들기 6단계 요약:

  1. 브라우저로 템플릿 목록 열기
  2. 업종에 맞는 템플릿 고르고 미리 보기
  3. 가게 이름, 글, 색상 바꾸기
  4. 카메라로 상품 사진 찍기
  5. 전화번호, 카카오톡, 주문 방법 넣기
  6. 무료로 사이트 게시하기

1. 브라우저로 템플릿 목록 열기

요즘 스마트폰은 작은 화면에 맞게 만든 도구만 있으면 홈페이지를 충분히 만들 수 있습니다. 크롬이나 사파리를 열고 무료 홈페이지 템플릿으로 가세요. 이 단계에서는 앱 설치도 회원 가입도 필요 없습니다.

이 글의 모든 단계는 휴대폰을 한 손에 들고 할 수 있어요. 사진: Dayne Topkin (CC0).

처음에는 와이파이를 쓰세요. 미리 보기와 사진 업로드가 더 빠릅니다.

2. 업종에 맞는 템플릿 고르고 미리 보기

검색창에 업종을 입력하거나 주제로 거르세요. 미리 보기를 누르면 실제로 작동하는 사이트가 열려, 손님 휴대폰에서 보이는 모습 그대로 확인할 수 있습니다. 마음에 들면 템플릿 사용을 누르세요.

이번 주 새 템플릿 두 가지: 맞춤 양복점 템플릿은 상황별 필터와 측정 예약이 있고, 시계·구두 수선 템플릿은 “어떤 증상인가요?”로 손님이 직접 서비스를 찾습니다. 둘 다 휴대폰만으로 수정할 수 있어요.

3. 가게 이름, 글, 색상 바꾸기

휴대폰 편집 화면은 편집 패널과 미리 보기로 나뉩니다. 위쪽 가운데의 컴퓨터 / 휴대폰 버튼으로, 휴대폰을 든 채 두 화면 크기를 모두 확인할 수 있어요.

  • 내용 탭: 가게 이름, 슬로건, 소개 글
  • 디자인 탭: 메인 색, 배경색, 로고
  • 수정할 때마다 미리 보기에 바로 반영됩니다

긴 글은 휴대폰으로 치기 힘드니 메모 앱에 먼저 써 두고 붙여 넣으세요.

4. 카메라로 상품 사진 찍기

여기는 휴대폰이 컴퓨터보다 잘하는 부분입니다. 상품을 추가하거나 사진을 바꿀 때 사진 촬영을 누르면 후면 카메라가 바로 열립니다. 사진은 자동으로 줄어들어 사이트가 빨리 열립니다.

편집 화면 안에서 바로 찍으니 사진을 컴퓨터로 옮길 필요가 없어요. 사진: Gabriel Santiago (CC0).

창가에서, 단색 배경에, 휴대폰을 똑바로 들고 찍으세요. 휴대폰으로 상품 사진 잘 찍는 법도 참고하세요. 양복점은 원단을 한 롤씩, 구두 수선집은 수선 전후 사진을 올리면 실력이 전해집니다.

5. 전화번호, 카카오톡, 주문 방법 넣기

연락처 탭에서 전화번호, 카카오톡, 주소, 영업시간을 넣으세요. 지도는 주소에 맞춰 자동으로 나옵니다. 주문을 깔끔하게 받고 싶다면 Google 설문지로 주문 받기를 켜세요. 주문이 한 줄씩 Google 스프레드시트에 쌓이고 휴대폰에서도 볼 수 있습니다.

6. 무료로 사이트 게시하기

사이트 게시를 누르고 사이트 이름을 정한 뒤 무료 GitHub 계정으로 로그인합니다. 계정이 없으면 로그인 화면에서 바로 만들 수 있고, 이것도 휴대폰으로 됩니다. 1~2분 뒤 HTTPS 주소로 사이트가 24시간 열립니다.

작은 가판대도 손님이 오기 전에 가격을 볼 수 있는 홈페이지가 있으면 좋아요. 사진: Wikimedia Commons (CC0).

게시한 뒤에는 카카오톡 채널과 SNS에 링크를 올리고 계산대에 QR 코드를 붙이세요.

휴대폰으로 만들 때 주의할 점

  • 초안은 그 기기 브라우저에 저장됩니다. 기기를 바꿀 때는 다운로드로 .zip을 저장한 뒤 파일에서 열기로 불러오세요.
  • 긴 가격표를 고칠 때는 휴대폰을 가로로 돌리세요.
  • 작업 중에는 브라우저 데이터를 지우지 마세요.

휴대폰으로 수정할 수 없는 도구도 있습니다. 예를 들어 구글 도움말에는 Google Sites는 컴퓨터에서만 수정할 수 있다고 나와 있어요. Kingpes, Google Sites, Wix 비교를 보고 고르세요.

컴퓨터와 휴대폰 모두의 전체 과정은 무료 홈페이지 만들기 7단계에 있습니다. 상품을 판다면 업종별 무료 쇼핑몰 템플릿도 보세요.

자주 묻는 질문

휴대폰으로 홈페이지를 만들려면 앱을 설치해야 하나요?

아니요. 크롬이나 사파리 같은 기본 브라우저로 Kingpes를 열고 템플릿을 골라 바로 수정하면 됩니다.

오래된 휴대폰도 되나요?

브라우저가 업데이트되어 있으면 됩니다. 최신 기기일수록 미리 보기가 부드럽지만 글과 사진 수정은 똑같습니다.

휴대폰에서 만든 초안이 사라지지 않나요?

초안은 그 기기의 브라우저에 저장됩니다. 다른 기기에서 이어 하려면 다운로드로 .zip 파일을 저장한 뒤 파일에서 열기로 불러오세요.

휴대폰에서 게시하면 비용이 드나요?

아니요. 무료 GitHub 계정이 필요하고 사이트 주소와 HTTPS도 무료입니다. 내 도메인만 매년 비용이 듭니다.
