무료 쇼핑몰 홈페이지 만들기: 코딩 없이 8단계

작은 가게가 무료 쇼핑몰 홈페이지를 만드는 방법: 템플릿 고르기, 상품과 가격 등록, 카카오톡이나 구글 설문지로 주문 받기, 결제와 배송까지 정리했습니다.

쇼핑몰을 만들려면 제작 업체에 맡기거나 매달 이용료를 내야 한다고 생각하기 쉽습니다. 사실 템플릿을 쓰면 무료 쇼핑몰 만들기가 가능합니다. 디자인을 고르고, 상품과 가격을 넣고, 주문 받는 방법을 정해 공개하면 끝이고 코딩은 전혀 필요 없습니다. 옷가게, 휴대폰 매장, 꽃집, 자전거 가게 같은 작은 가게를 위해 단계별로 설명합니다.

한눈에 보기, 쇼핑몰 홈페이지 8단계:

  1. 판매용 홈페이지에 필요한 것
  2. 파는 상품에 맞는 템플릿 고르기
  3. 상품, 가격, 실제 사진 등록
  4. 카카오톡, 전화, 구글 설문지로 주문 받기
  5. 결제와 배송
  6. 교환·반품 규정, 영업시간, 지도
  7. 공개하고 링크 알리기
  8. 장바구니와 온라인 결제가 필요할 때

1. 판매용 홈페이지에 필요한 것

손님이 알고 싶은 것은 무엇을 파는지, 얼마인지, 어떻게 주문하는지 세 가지입니다. 작은 가게에 필요한 것은:

  • 카테고리별로 나뉘고 검색·필터가 되는 상품 목록.
  • 실제 사진, 가격, 사이즈나 색상, 재고 여부가 있는 상품 상세 페이지.
  • 카카오톡, 전화, 주문서로 바로 이어지는 분명한 주문 버튼.
  • 신뢰 정보: 주소, 영업시간, 교환·반품 규정, 후기.

긴 회사 소개나 화려한 효과는 필요 없습니다. 손님은 원하는 상품을 찾아 빨리 주문하고 싶어 합니다.

2. 파는 상품에 맞는 템플릿 고르기

업종별 템플릿에는 위 요소가 이미 다 들어 있어 내용만 바꾸면 됩니다.

꽃집 템플릿은 용도와 크기별로 꽃다발을 나눠 손님이 더 빨리 고릅니다. 사진: rawpixel (CC0)

  • 의류: 종류·사이즈·가격으로 필터, 마우스를 올리면 두 번째 사진. 옷가게 홈페이지 템플릿 보기.
  • 휴대폰·태블릿: 용량을 고르면 가격, 할부금, 보상 판매 표시. 휴대폰 매장 템플릿 보기.
  • 꽃집: 용도와 꽃 종류로 필터, 크기 선택, 배달 주문서.
  • 자전거·전기자전거: 종류와 가격대로 필터, 시승 예약.

딱 맞는 업종이 없으면 가장 비슷한 것을 고르세요. 카테고리 이름과 버튼은 모두 바꿀 수 있습니다.

3. 상품, 가격, 실제 사진 등록

가장 중요한 부분입니다. **“템플릿 사용”**을 누르고 상품 탭을 열어 상품마다:

밝은 곳에서 같은 배경으로 찍은 실제 사진은 목록을 깔끔하고 믿음직하게 보이게 합니다. 사진: Image Catalog (CC0)

  • 차이가 보이는 이름: “2겹 바람막이 재킷, 올리브”.
  • 분명한 가격, 할인 중이면 원래 가격도. “가격은 DM”은 이탈의 원인입니다.
  • 창가에서 휴대폰으로 같은 배경에 찍은 실제 사진. 다른 사이트 사진은 분쟁 위험이 있고 손님도 의심합니다.
  • 사이즈, 색상, 옵션과 재고 여부.

상품이 많다면 **“스프레드시트로 일괄 수정”**을 쓰세요. 표를 내려받아 구글 스프레드시트나 엑셀에서 이름과 가격을 고친 뒤 한 번에 가져오면 됩니다.

4. 카카오톡, 전화, 구글 설문지로 주문 받기

무료 홈페이지는 서버가 필요 없어서, 주문은 평소 쓰던 방법으로 바로 들어옵니다.

  • 카카오톡, 인스타그램: 손님이 버튼을 누르면 상품·사이즈·가격이 담긴 주문 문구가 미리 작성됩니다.
  • 전화: 상담이 필요하거나 말로 주문하고 싶은 손님용.
  • 구글 설문지: 손님이 홈페이지에서 이름, 전화번호, 주소를 입력하면 내 구글 스프레드시트에 한 건씩 저장됩니다. 설문지 응답 저장 위치에 대한 구글 도움말 참고.

가장 빨리 답할 수 있는 채널 한두 개만 고르세요. 채널이 많아도 답이 늦으면 주문을 놓칩니다.

5. 결제와 배송

홈페이지는 상품을 보고 주문하는 곳이고, 결제와 배송은 메시지로 팔 때와 같습니다.

깔끔한 포장과 작은 감사 카드는 손님이 가게를 기억하고 다시 찾게 합니다. 사진: rawpixel (CC0)

  • 계좌이체·간편결제: 주문 확인 때 계좌나 결제 링크를 보내기.
  • 매장 수령 시 결제: 가능한 경우를 명시.
  • 배송비: 지역별 금액, 얼마 이상 무료인지 홈페이지에 미리 적기.
  • 지역별 배송 기간 안내.

홈페이지에 적어 두면 같은 질문에 몇 번씩 답하지 않아도 됩니다.

6. 교환·반품 규정, 영업시간, 지도

온라인으로 처음 사는 손님은 “안 맞으면 어떡하지?”를 걱정합니다. 짧은 규정 페이지가 주문을 도와줍니다.

홈페이지와 지도의 영업시간이 정확하면 손님이 닫힌 문 앞에서 돌아가는 일이 없습니다. 사진: Álvaro Serrano (CC0)

  • 교환·반품: 며칠 이내, 조건(택 부착, 미사용), 배송비 부담. Kingpes 템플릿에는 규정 페이지가 준비되어 있어 날짜만 바꾸면 됩니다.
  • 영업시간과 휴무일. “영업 중”, “영업 종료”를 자동으로 표시합니다.
  • 주소로 표시되는 지도와 길찾기 버튼. 네이버 지도와 구글 지도에도 등록하세요: 구글 지도에 가게 등록하는 방법.

7. 공개하고 링크 알리기

다 고쳤으면 **“홈페이지 공개”**를 누르세요. 24시간 무료로 운영되고 HTTPS가 적용되며 휴대폰에서도 보기 좋습니다. 이제 손님을 만나는 모든 곳에 링크를 두세요.

  • 인스타그램·틱톡 프로필, 카카오톡 채널에 고정.
  • 가격을 묻는 손님에게 사진을 하나씩 보내는 대신 링크 보내기.
  • 계산대, 쇼핑백, 명함에 QR 코드 인쇄.
  • 지도 프로필에도 링크 추가.

yourshop.kr 같은 쉬운 주소를 원하면 나중에 도메인을 사서 연결하면 되고, 홈페이지를 다시 만들 필요는 없습니다.

8. 장바구니와 온라인 결제가 필요할 때

작은 가게라면 카카오톡이나 구글 설문지 주문으로 대부분 충분합니다. 손님과 직접 대화할 수 있기 때문입니다. 다음과 같을 때는 장바구니와 결제가 필요할 수 있습니다.

  • 주문이 너무 많아 메시지 답장이 밀린다.
  • 한 번에 여러 상품을 사는 손님이 많아 합계를 자동으로 계산하고 싶다.
  • 먼 곳의 손님에게 주문과 동시에 결제를 받고 싶다.

그때는 Kingpes Pro 패키지(전체 소스 코드, 장바구니, 온라인 결제, 전용 서버)를 보거나, 무료로 시작해 나중에 업그레이드하세요.

이제 막 시작한다면 가게용 무료 홈페이지 만들기 5분 가이드를 읽거나 무료 홈페이지 템플릿에서 하나를 고르세요.

자주 묻는 질문

무료 쇼핑몰에 상품 수 제한이 있나요?

Kingpes 판매용 템플릿은 수십~수백 개 상품을 기준으로 만들어졌고, 옷가게 템플릿에는 샘플 상품이 약 190개 들어 있습니다. 작은 가게는 보통 수십 개면 충분합니다.

무료 홈페이지에 장바구니와 온라인 결제가 있나요?

없습니다. 손님이 상품을 골라 카카오톡, 전화, 구글 설문지로 주문을 보내고 계좌이체나 매장 수령 시 결제합니다. 장바구니와 결제가 필요하면 Pro 패키지를 보세요.

구글 설문지 주문은 어디로 가나요?

내 구글 스프레드시트에 주문 한 건이 한 줄(이름, 전화번호, 상품, 메모)로 자동 저장되고, 휴대폰에서도 볼 수 있습니다.

도메인을 사야 하나요?

처음에는 필요 없습니다. 무료 주소(HTTPS)로 바로 운영할 수 있고, yourshop.kr 같은 쉬운 주소가 필요해지면 나중에 도메인을 사서 연결하면 됩니다.
