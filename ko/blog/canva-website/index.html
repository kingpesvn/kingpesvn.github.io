캔바로 홈페이지 만들기 vs 템플릿, 무엇이 나을까

캔바로 홈페이지 만들기는 빠르고 예쁘지만 장바구니와 예약이 없어요. 미리 만든 템플릿과 비교해 가게에 맞는 방법을 고르세요.

포스터와 SNS 이미지로 익숙한 캔바로 캔바로 홈페이지 만들기를 생각하는 사장님이 많아요. 반나절이면 보기 좋은 소개 페이지를 만들 수 있죠. 하지만 손님이 직접 상품을 고르고 가격을 보고 예약해야 할 때는 부족한 점이 보여요. 이 글은 캔바와 템플릿을 비교해 처음부터 알맞게 고르도록 도와드려요.

요약: 고르기 전에 알아 둘 5가지

  1. 캔바로 할 수 있는 것
  2. 판매에 캔바가 부족한 점
  3. 템플릿은 무엇이 다른가
  4. 빠른 비교표
  5. 어떤 방법을 고를까

1. 캔바로 홈페이지 만들기, 무엇을 할 수 있나요?

캔바는 브라우저 디자인 도구로, 디자인을 웹페이지로 바꾸는 기능이 있어요. 레이아웃을 고르고 글, 사진, 버튼을 배치해 캔바가 주는 무료 주소로 게시해요. 개인 도메인은 요금제에 따라 보통 유료예요.

가게 이름, 사진 몇 장, 전화번호만 있는 소개 페이지라면 캔바로 충분해요. 사진: Pixel.la (CC0).

장점은 예쁘고 익숙하다는 것. 행사 페이지, 짧은 메뉴, 개인 프로필이라면 캔바로 충분해요.

2. 판매하려면 캔바에 무엇이 부족할까?

캔바 사이트는 디자인을 웹으로 내보낸 것이라 가게에 매일 필요한 기능이 대부분 없어요.

  • 장바구니·상품 필터 없음: 상품과 사이즈를 골라 주문을 보낼 수 없어요.
  • 가격 계산·예약 없음: 학원이 수업료를 보여 주거나 정비소가 시간 예약을 받을 수 없어요.
  • 휴대폰에서 깨지기 쉬움: PC에서 배치한 디자인이 작은 화면에서 겹쳐 손봐야 할 때가 있어요.
  • 구글 설정 제한: 페이지별 제목·설명, 다국어가 제한되는 경우가 많아요.

결국 방문자는 메시지로 가격을 묻고 사장님이 한 명씩 답해야 해요.

3. 템플릿은 무엇이 다를까?

템플릿은 업종별로 만들어져 어려운 부분이 이미 되어 있어요. 예를 들어 게임 가게 템플릿은 기종·새 제품/중고로 거르고 중고 매입가를 장바구니에서 빼 줘요. 과외 센터 템플릿은 학년, 과목, 주 횟수로 수업료와 체험일을 계산해요.

직접 배치하는 건 조각을 하나씩 맞추는 일, 템플릿은 완성된 그림이에요. 사진과 글만 바꾸면 돼요. 사진: Hans-Peter Gauster (CC0).

바꿀 것은 가게 이름, 사진, 가격, 전화번호뿐. 모바일 화면, 전화 버튼, 주문 폼이 바로 작동해요.

비용무료, 개인 도메인 유료무료, 개인 도메인 선택

5. 어떤 것을 고를까?

행사나 캠페인용으로 몇 주만 쓸 짧은 소개 페이지이고 문의는 메시지로 충분하다면 캔바.

손님이 직접 상품과 가격을 보고 주문·예약까지 하길 원한다면 템플릿. 대부분 가게에서 길게 보면 답장 수고가 훨씬 줄어요.

둘 다 쓸 수 있나요?

캔바는 홈페이지용 배너와 홍보 이미지를 만들 때 여전히 유용해요. 사진: Thought Catalog (CC0).

네, 그게 좋아요. 캔바로 배너와 홍보 이미지를 만들어 템플릿에 넣으세요. 판매는 홈페이지, 디자인은 캔바가 맡아요.

전체 단계는 무료 홈페이지 만들기 안내에서, 구글 사이트 비교와 코딩 없이 홈페이지 만들기도 함께 보세요. 디자인은 템플릿 모음에서 고를 수 있어요.

자주 묻는 질문

캔바 홈페이지는 무료인가요?

캔바가 주는 주소로는 무료로 게시할 수 있어요. 개인 도메인과 일부 기능은 보통 유료이고 요금은 바뀔 수 있으니 공식 페이지를 확인하세요.

캔바로 쇼핑몰을 만들 수 있나요?

한 페이지 소개에 알맞아요. 장바구니, 상품 필터, 가격이 나오는 예약 폼이 없어 손님은 결국 메시지로 문의하게 돼요.

캔바 디자인을 템플릿에 쓸 수 있나요?

네. 배너와 홍보 이미지를 캔바로 만들어 내려받은 뒤 템플릿의 상단 사진이나 상품 사진과 바꾸면 돼요.

캔바에서 템플릿으로 옮기기 어렵나요?

어렵지 않아요. 소개 글, 사진, 가격을 새 템플릿에 옮겨 게시하고 SNS 프로필 링크만 바꾸면 돼요.
