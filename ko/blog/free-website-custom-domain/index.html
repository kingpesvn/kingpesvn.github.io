무료 홈페이지 개인 도메인 연결: 비용과 4단계

무료 홈페이지 개인 도메인 연결 방법. 계속 무료인 부분, 매년 내는 비용, 도메인 고르고 사는 법, 4단계로 홈페이지에 연결하는 법을 정리했습니다.

도메인이 있는 무료 홈페이지를 찾았다가 2년 차에 몇 배 비싼 갱신비 청구서를 받는 경우가 많습니다. 사실은 간단합니다. 홈페이지를 만들고 올리는 것은 계속 무료일 수 있지만, 도메인은 매년 조금씩 비용이 듭니다. 이 글은 무료 홈페이지 개인 도메인 연결 방법으로, 무료인 부분, 도메인 고르고 사는 법, 4단계 연결 방법을 설명합니다.

빠른 요약, 알아 둘 6가지:

  1. 개인 도메인이란, 왜 무료일 수 없나
  2. 무료인 것과 돈이 드는 것
  3. 손님이 기억하는 도메인 고르기
  4. 어디서 사고 갱신비는 어떻게 보나

1. 개인 도메인이란? 왜 무료일 수 없나?

도메인 네임은 손님이 홈페이지에 들어오려고 입력하는 주소로, 예를 들면 saltlinefish.com입니다. 집 주소와 같아서, 집(홈페이지)은 어디에 있든 손님이 기억하고 명함, 쇼핑백, 간판에 인쇄하는 것은 이 주소입니다.

도메인은 국제·국가 등록 기관이 관리하고, 한 이름은 기간마다 한 명의 주인만 가질 수 있습니다. 그래서 누구나 등록비와 매년 갱신비를 냅니다. “평생 무료 도메인”을 내세우는 곳은 대개 shop.platform.com 같은 하위 도메인을 주거나 첫해만 무료입니다.

2. 무료인 것과 돈이 드는 것

홈페이지는 세 부분으로 되어 있고, 돈이 드는 것은 하나뿐입니다.

  • 홈페이지 제작: 템플릿을 쓰면 무료. 글, 가격, 사진만 바꾸면 됩니다.
  • 호스팅: 정적 홈페이지는 GitHub Pages에서 무료, HTTPS 포함. 무료 호스팅 글도 참고하세요.
  • 개인 도메인: 도메인 등록 업체에 매년 냅니다.

개인 도메인이 없어도 your-name.github.io 같은 주소로 홈페이지는 돌아갑니다. 이렇게 시작해 몇 주 운영해 보고, 가게 이름이 확정되면 도메인을 사도 됩니다.

3. 손님이 기억하는 도메인 고르기

좋은 도메인은 한 번 듣고 바로 맞게 입력할 수 있는 주소입니다.

  • 짧게, 가능하면 하이픈 없이: bluerose.kr이 blue-rose-shop-24h.kr보다 쉽습니다.
  • 간판, SNS 이름과 같거나 비슷하게.
  • 다른 사람에게 소리 내어 읽어 보고 “어떻게 써요?”라고 되물으면 바꾸세요.
  • 손님에 맞게 끝자리 선택: 국내 손님은 .kr, 해외에도 팔면 .com.

도메인은 번지수와 같습니다. 짧고 분명해서 한눈에 읽혀야 합니다. 사진: Daniel von Appen (CC0)

사용 가능 여부는 등록 업체 사이트에서 바로 확인할 수 있습니다. 원하는 이름이 이미 있으면 숫자를 붙이기보다 지역명이나 업종을 붙이세요.

4. 어디서 사고 갱신비는 어떻게 보나

도메인은 인증된 등록 업체에서 삽니다. .com은 보통 1년에 1만5천~3만 원, .kr은 조금 더 비쌉니다. 가격은 업체와 시기에 따라 다르며, 이 글의 정보는 작성 시점(2026년 11월) 기준입니다.

도메인은 1년 단위입니다. 첫해 할인가만 보지 말고 2년 차 갱신비를 확인하세요. 사진: Brooke Lark (CC0)

결제 전에 2년 차 갱신비, 다른 업체로 옮길 때 수수료, 소유자 정보 보호 포함 여부를 확인하세요. 호스팅이 이미 무료라면 도메인과 호스팅 묶음 상품은 필요 없습니다. “끼워 주는 무료 도메인”이 왜 문제인지는 무료 도메인, 가게에 써도 될까?에서 볼 수 있습니다.

5. 4단계로 도메인 연결하기

GitHub Pages 홈페이지와 도메인이 있으면 연결은 10분 정도면 됩니다.

  1. GitHub에 도메인 입력: 홈페이지 저장소에서 Settings → Pages를 열고 Custom domain에 입력합니다.
  2. 등록 업체에서 DNS 추가: 루트 도메인을 GitHub Pages로 향하게 하는 A 레코드 4개, www를 your-name.github.io로 향하게 하는 CNAME 1개를 추가합니다.
  3. DNS 반영 기다리기: 보통 몇 분에서 몇 시간.
  4. Enforce HTTPS 켜기: GitHub가 무료 인증서를 발급하고 브라우저에 자물쇠가 표시됩니다.

입력할 IP 주소는 GitHub Pages 문서에 있습니다. 한 글자라도 틀리면 Settings 화면에 DNS 확인 오류가 뜨니 고치면 됩니다.

6. 예시: 이번 주 새 템플릿 2개

수산물 가게 템플릿은 미국 부두의 생선 가게로, “오늘 들어온 생선” 보드, 제철 달력, 무게로 계산하는 주문표가 있습니다. 이런 가게는 얼음 봉투와 시장 간판에 도메인을 인쇄해 단골이 내일 것을 주문하게 합니다.

생선 가게라면 봉투에 인쇄한 도메인이 손님을 다시 부르는 가장 빠른 길입니다. 사진: paul morris (CC0)

반려견 훈련 템플릿에는 남은 자리가 보이는 개강일, 클래스 추천 퀴즈, 자동으로 가격이 나오는 개인 레슨 패키지가 있습니다. 자세한 내용은 반려견 훈련소 홈페이지 무료로 만들기를 보세요.

반려견 훈련은 입소문으로 크는 일입니다. 말하기 쉬운 도메인이어야 들은 사람이 바로 찾습니다. 사진: Justin Veenema (CC0)

어떻게 시작할까?

홈페이지 먼저, 도메인은 나중에. 업종에 맞는 템플릿을 고르고 글과 사진을 바꾸면 약 5분 만에 올릴 수 있습니다. 가게 이름이 정해지면 도메인을 사서 위의 4단계로 연결하세요. 전체 과정은 무료 홈페이지 만들기 안내에, 템플릿은 템플릿 모음에 있습니다.

자주 묻는 질문

.com 도메인을 완전히 무료로 받을 수 있나요?

거의 불가능합니다. .com, .net, .kr 모두 등록비와 매년 갱신비가 있습니다. "무료 도메인"은 보통 첫해만 무료이거나 호스팅 계약과 묶여 있습니다.

개인 도메인을 쓰면 호스팅 비용이 생기나요?

아니요. GitHub Pages에 올린 정적 홈페이지는 개인 도메인을 붙여도 HTTPS 인증서까지 무료입니다. 도메인 값만 내면 됩니다.

연결하고 얼마 후에 접속되나요?

보통 몇 분에서 몇 시간, DNS 반영에 최대 24시간이 걸리기도 합니다. 그동안 기존 your-name.github.io 주소는 그대로 쓸 수 있습니다.

갱신을 잊으면 어떻게 되나요?

홈페이지는 GitHub에 남아 있지만 도메인이 연결되지 않아 손님이 접속할 수 없습니다. 자동 갱신을 켜고 자주 보는 이메일로 등록하세요.
