무료 웹호스팅: 24시간 돌아가는 HTTPS 홈페이지

무료 웹호스팅은 오래 쓸 수 있을까요? 무료 호스팅의 종류, HTTPS가 무엇인지, 알아 둘 제한, 비용 없이 가게 홈페이지를 24시간 돌리는 방법을 정리했습니다.

홈페이지에는 도메인 말고도 머무를 곳, 즉 호스팅이 필요합니다. 많은 사장님이 무료 웹호스팅을 오래 쓸 수 있는지, 느리지 않은지, 광고가 붙는지, HTTPS가 되는지 궁금해합니다. 이 글은 무료 호스팅의 종류, 알아 둘 제한, 비용 없이 홈페이지를 24시간 돌리는 방법을 간단히 설명합니다.

1. 호스팅이란?

호스팅은 홈페이지 파일을 저장해 두었다가 누가 페이지를 열 때마다 브라우저로 보내는 서버입니다. 도메인이 주소라면 호스팅은 집입니다. 호스팅이 없으면 도메인이 있어도 아무도 들어올 수 없습니다.

모든 홈페이지 뒤에는 밤낮으로 돌아가는 서버가 있습니다. 사진: rawpixel (CC0)

작은 가게 홈페이지는 글, 사진, 연락 버튼이 대부분이라 강력한 서버가 필요 없습니다.

2. 무료 호스팅의 종류

크게 세 가지가 있습니다.

  • 호스팅 포함 홈페이지 빌더(Wix, 구글 사이트 도구 등): 가입하면 바로 게시되지만 무료판은 하위 도메인이고 광고가 붙는 곳도 있습니다.
  • 무료 정적 호스팅(GitHub Pages, Cloudflare Pages, Netlify 등): 소개 페이지, 메뉴, 가격표처럼 서버에서 코드를 돌리지 않는 사이트용. 빠르고 안정적입니다.
  • 전통적인 무료 호스팅 플랜: 용량이 작고 광고가 붙거나 프로모션이 끝나면 중단되기도 합니다.

작은 가게라면 정적 호스팅이 가장 오래가는 선택입니다.

3. HTTPS란, 왜 필요한가?

HTTPS는 브라우저와 홈페이지 사이의 데이터를 암호화하며 주소창에 자물쇠로 표시됩니다. HTTPS가 없으면 브라우저가 “주의 요함”이라고 띄워 고객이 상품을 보기도 전에 떠날 수 있습니다.

HTTPS는 자물쇠 같아서 작동 방식은 안 보여도 없으면 바로 눈에 띕니다. 사진: Bich Tran (CC0)

요즘은 무료로 자동 갱신되는 HTTPS 인증서가 흔하니 자물쇠 하나 때문에 돈을 더 낼 필요는 없습니다.

4. “24시간 운영”과 제한

정적 호스팅은 전 세계 서버에 사본을 두어 한 대가 고장 나도 계속 열립니다. 대신 제한이 있으며, 작성 시점 GitHub 문서 기준으로 GitHub Pages는:

  • 사이트 용량 약 1GB, 월 전송량 약 100GB 제한이 있으며 작은 가게에는 충분합니다.
  • 온라인 결제가 주목적인 사이트용이 아니며, 상품 소개와 메시지·폼 주문에 맞습니다.
  • 수정 후 새 내용이 보이기까지 몇 분 걸릴 수 있습니다.

5. Kingpes 홈페이지는 어디에 있나?

게시하기를 누르면 Kingpes가 본인의 무료 GitHub 계정에 있는 GitHub Pages에 홈페이지를 올립니다. 주소는 username.github.io/shop 형태이고 HTTPS가 자동으로 켜지며, 언제든 개인 도메인을 연결할 수 있습니다.

홈페이지가 본인 계정에 있으니 소유권을 지키고 한 업체에 묶이지 않습니다.

어떻게 시작하나요?

서버를 몰라도 됩니다. 템플릿을 고르고 게시만 하면 됩니다. 사진: rawpixel (CC0)

업종에 맞는 템플릿을 골라 글과 사진을 바꾸고 게시하세요. 호스팅과 HTTPS는 처음부터 포함됩니다. 단계는 무료 홈페이지 만들기, 비용은 쇼핑몰 제작 비용, 코딩 없이 홈페이지 만들기에 있고, 지금 바로 템플릿 라이브러리에서 고를 수도 있습니다.

자주 묻는 질문

무료 호스팅은 안전한가요?

서비스에 따라 다릅니다. GitHub Pages 같은 대형 회사의 정적 호스팅은 HTTPS가 있고 안정적이지만, 출처가 불분명한 무료 플랜은 광고를 넣거나 갑자기 종료되기도 합니다.

Kingpes 홈페이지는 어디에 올라가나요?

본인의 무료 GitHub 계정에 있는 GitHub Pages입니다. 주소는 username.github.io/shop 형태이고 HTTPS가 자동으로 켜집니다.

HTTPS에 돈을 내야 하나요?

아니요. 무료로 자동 갱신되는 인증서를 주는 곳이 많고, Kingpes는 개인 도메인을 연결해도 HTTPS가 켜져 있습니다.

무료 호스팅으로 온라인 판매가 되나요?

상품 소개와 메신저·전화·구글 폼 주문은 됩니다. 온라인 결제는 보통 서버와 유료 플랜이 필요합니다.
