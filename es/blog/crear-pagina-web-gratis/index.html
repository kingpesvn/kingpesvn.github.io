Crear una web gratis para tu negocio en 5 minutos: 7 pasos

Cómo crear una página web gratis para un pequeño negocio en 7 pasos y sin programar: elige plantilla, añade productos, recibe pedidos y publica sin coste.

Por Kingpes · Publicado 9 de octubre de 2026 · 5 min de lectura

En este artículo

  1. 1. Elige una plantilla de tu sector
  2. 2. Cambia el nombre, el logo y los colores
  3. 3. Añade productos, precios y fotos reales
  4. 4. Añade contacto y forma de pedir
  5. 5. Publica tu web gratis
  6. 6. Conecta tu propio dominio (opcional)
  7. 7. Lleva tu web a tus clientes
  8. ¿Qué límites tiene una web gratis?

¿Tienes un pequeño negocio y quieres que te encuentren en Google, pero crees que una web es cara, lenta y técnica? En realidad puedes crear una página web gratis para tu negocio solo con el móvil o el ordenador, y tener la primera versión lista en unos 5 minutos. Esta guía te lleva paso a paso, desde elegir la plantilla hasta ver tu web publicada.

Resumen rápido, 7 pasos para crear una página web gratis para tu negocio:

  1. Elige una plantilla de tu sector
  2. Cambia el nombre, el logo y los colores
  3. Añade productos, precios y fotos reales
  4. Añade contacto y forma de pedir
  5. Publica tu web gratis
  6. Conecta tu propio dominio (opcional)
  7. Lleva tu web a tus clientes

1. Elige una plantilla de tu sector

El paso más importante es elegir una plantilla hecha para tu tipo de negocio.

Cada sector necesita apartados distintos: una panadería, carta con precios; una cafetería, bebidas por tamaño. Foto: rawpixel (CC0).

Una plantilla del sector ya trae lo que buscan tus clientes: la de panadería tiene productos con precio, la de cafetería tiene carta por tamaños y horario, la de spa tiene tarifas y reservas. No diseñas nada, solo cambias el contenido.

Abre la biblioteca de plantillas web gratis, filtra por categoría y pulsa Vista previa para ver la versión real en el móvil. ¿Te gusta? Pulsa Usar plantilla. Por ejemplo: plantilla web para panadería, plantilla para cafetería, plantilla para spa.

2. Cambia el nombre, el logo y los colores

La plantilla se abre en el editor con la vista previa al lado. Lo que cambies aparece al instante en la vista previa.

En la pestaña Contenido, escribe el nombre del negocio, una frase corta de presentación y la foto de portada. En Diseño, elige el color principal según tu rótulo o logo y cambia el texto de los botones, por ejemplo “Encargar tarta” en lugar de “Pedir”.

Consejo: haz la frase de presentación corta y di qué vendes y dónde, por ejemplo “Tartas recién hechas cada mañana, envío en todo Valencia”. Se entiende al instante y Google también entiende de qué trata tu web.

3. Añade productos, precios y fotos reales

Es lo que más miran los clientes, así que dedícale tiempo.

Precios claros, como las etiquetas de una estantería, ayudan a decidir rápido sin preguntar. Foto: rawpixel (CC0).

En la pestaña Productos, crea categorías (por ejemplo tartas, pan, bebidas) y añade cada producto con nombre, precio y fotos. En el móvil puedes hacer la foto directamente con la cámara al añadir un producto. Pon 1–3 fotos reales con buena luz por producto.

Si tienes muchos productos, usa la descarga en hoja de cálculo .csv para editarlo todo en Excel o Google Sheets y vuelve a importarlo. Si vendes en varios países, cada uno tiene sus precios y su moneda.

4. Añade contacto y forma de pedir

Una web solo sirve si el cliente puede contactarte justo cuando quiere comprar.

El cliente quiere preguntar talla y precio enseguida: el botón de pedido debe estar a la vista. Foto: Artem Beliaikin (CC0).

En la pestaña Contacto, añade teléfono, WhatsApp, dirección (el mapa sigue la dirección) y horario. Para ordenar los pedidos, activa pedidos con Google Form: cada pedido se convierte en una fila de tu Google Sheets y puedes activar un aviso por email para cada pedido nuevo.

Esta pestaña también tiene enlaces de apps de reparto, aviso de cierre por vacaciones, política de devoluciones y el código QR de tu web.

5. Publica tu web gratis

Cuando la vista previa te convenza, pulsa Publicar. Elige un nombre para la web (va en la dirección) e inicia sesión con una cuenta gratuita de GitHub. GitHub guarda y sirve tu web, con HTTPS (el candado del navegador) incluido.

En 1–2 minutos tu web está en línea 24/7. Está en tu propia cuenta, así que es tuya. Para cambiar algo, vuelve al editor, edita y pulsa Actualizar web.

¿Aún no quieres crear una cuenta? Puedes descargar la web como archivo .zip para guardarla o que alguien la publique más tarde.

6. Conecta tu propio dominio (opcional)

La dirección gratis tiene la forma tucuenta.github.io/tunegocio y funciona al momento. Si quieres una dirección corta para el rótulo, como tunegocio.es, compra un dominio en un proveedor (normalmente anual) y elige Tu propio dominio al publicar.

El editor muestra los registros DNS que debes añadir en tu proveedor, con botones Copiar y Comprobar dominio. Cuando el dominio apunta bien, el HTTPS se activa solo. No hay más coste que el del dominio.

7. Lleva tu web a tus clientes

Tener web no hace que lleguen visitas solas. Ponla en todos los lugares donde los clientes ya te ven.

Como la pizarra de la puerta, la web necesita novedades: productos, precios, ofertas. Foto: pixellaphoto (CC0).

  • Imprime el código QR de tu web (descárgalo en la pestaña Contacto) para el mostrador, las mesas y las bolsas.
  • Añade el enlace en Google Maps con tu Perfil de Empresa de Google, para que quien busque “panadería cerca de mí” vea también tu web.
  • Pon el enlace en Instagram, Facebook, TikTok y WhatsApp Business, y en la firma de tus mensajes.
  • Actualiza a menudo: novedades, precios, horarios de festivos. La información al día da confianza.

¿Qué límites tiene una web gratis?

Para que elijas bien:

  • Aún no hay pago online ni carrito. Los clientes piden por teléfono, WhatsApp o Google Form, y tú confirmas y cobras como ahora.
  • Necesitas una cuenta de GitHub para publicar. Es gratis y se crea en minutos; la página de acceso tiene botón de registro.
  • Tener web no significa salir primero en Google enseguida. Hace falta tiempo, contenido claro y actualizaciones.

Si tu negocio necesita carrito, pago online o servidor propio, mira el plan avanzado. Si solo quieres una web bonita para que te encuentren, vean tus productos y te pidan, la versión gratis es suficiente.

Empieza ya: entra en la portada de Kingpes, escribe tu sector en el buscador y elige una plantilla. La primera versión te llevará unos 5 minutos.

Preguntas frecuentes

¿Crear una página web gratis es realmente gratis?

La plantilla, el editor, la dirección web y el HTTPS son gratis. Solo pagas si quieres un dominio propio como tunegocio.es, que se paga cada año a la empresa de dominios.

¿Puedo crear una web sin saber programar?

Sí. Escribes textos, cambias fotos y precios en campos ya preparados; el diseño y la versión móvil ya están hechos.

¿Una web gratis puede recibir pedidos?

Sí. Los clientes llaman, escriben por WhatsApp o rellenan un Google Form que envía cada pedido a tu Google Sheets. Todavía no hay pago online.

¿Qué cuenta necesito para publicar?

Una cuenta gratuita de GitHub, que guarda y sirve tu web. Si aún no quieres crearla, puedes descargar la web como archivo .zip.
