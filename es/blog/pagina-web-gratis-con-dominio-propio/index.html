Página web gratis con dominio propio: ¿cuánto cuesta?

Cómo tener una página web gratis con dominio propio: qué sigue gratis, qué pagas cada año, cómo elegir y comprar el dominio y conectarlo en 4 pasos.

Mucha gente busca una web gratis con dominio y en el segundo año recibe una factura de renovación varias veces más cara. La realidad es más sencilla: crear y alojar la web puede ser gratis durante años, mientras que el dominio siempre cuesta un poco cada año. Esta guía explica cómo montar una página web gratis con dominio propio: qué no cuesta nada, cómo elegir y comprar el dominio y los 4 pasos para conectarlo.

1. ¿Qué es un dominio propio y por qué no puede ser gratis?

Un dominio de internet es la dirección que escriben tus clientes para entrar en tu web, por ejemplo saltlinefish.com. Funciona como una dirección postal: la casa (la web) puede estar en cualquier sitio, pero lo que la gente recuerda e imprimes en tarjetas, bolsas y rótulos es la dirección.

Los dominios los gestionan registros internacionales y nacionales. Cada nombre tiene un único dueño durante un periodo, así que todo el mundo paga alta y renovación anual. Los servicios que prometen “dominio gratis para siempre” suelen darte un subdominio como tienda.plataforma.com, o solo es gratis el primer año.

2. ¿Qué es gratis y qué se paga?

Una web tiene tres partes y solo una cuesta dinero:

  • Crear la web: gratis con una plantilla lista; solo cambias textos, precios y fotos.
  • Alojamiento (hosting): gratis para una web estática en GitHub Pages, con HTTPS. Mira hosting gratis.
  • Dominio propio: se paga cada año al registrador.

Sin dominio propio, tu web funciona igual en una dirección como your-name.github.io. Puedes empezar así, probar unas semanas y comprar el dominio cuando el nombre de la tienda esté decidido.

3. Elegir un dominio que la clientela recuerde

Un buen dominio se escribe bien después de oírlo una vez. Algunas reglas:

  • Corto y, si se puede, sin guiones: rosaazul.es es más fácil que rosa-azul-tienda-24h.es.
  • Igual o parecido al nombre del rótulo y de las redes sociales.
  • Dilo en voz alta: si te preguntan “¿cómo se escribe?”, cámbialo.
  • Elige la terminación según tus clientes: la del país para venta local, .com si vendes a varios países.

Un dominio es como el número de una casa: corto, claro y legible de un vistazo. Foto: Daniel von Appen (CC0).

Comprueba la disponibilidad en la web del registrador. Si el nombre que quieres está ocupado, añade tu ciudad o tu oficio en lugar de un número.

4. Dónde comprarlo y el precio de renovación

Compra en un registrador acreditado. Un .com suele costar entre 10 y 20 euros al año; algunas terminaciones de país cuestan más. Los precios cambian; los datos son correctos en el momento de escribir (noviembre de 2026).

El dominio se paga por años: mira la renovación desde el segundo año, no solo la oferta del primero. Foto: Brooke Lark (CC0).

Antes de pagar, revisa tres cosas: el precio de renovación del segundo año, la tarifa por trasladar el dominio y si incluye privacidad del titular. Evita los paquetes de dominio más alojamiento si tu alojamiento ya es gratis. Lee dominio gratis para tiendas: ¿vale la pena? para ver por qué los dominios “de regalo” dan problemas.

5. Conectar el dominio en 4 pasos

Con tu web en GitHub Pages y un dominio, unirlos lleva unos 10 minutos:

  1. Indica el dominio a GitHub: en el repositorio de la web, abre Settings → Pages y escríbelo en Custom domain.
  2. Añade registros DNS en el registrador: cuatro registros A que apuntan el dominio raíz a GitHub Pages y un CNAME para www hacia your-name.github.io.
  3. Espera al DNS: normalmente de minutos a pocas horas.
  4. Activa Enforce HTTPS: GitHub emite un certificado gratis y aparece el candado en el navegador.

Las direcciones IP que hay que poner están en la documentación de GitHub Pages. Si te equivocas en una, GitHub muestra un error de comprobación DNS en Settings y basta con corregirlo.

Preguntas frecuentes

¿Puedo conseguir un dominio .com totalmente gratis?

Prácticamente no. Los .com, .net, .es y similares cobran alta y renovación anual. Las ofertas de "dominio gratis" suelen serlo solo el primer año o te atan a su alojamiento.

¿Con dominio propio el alojamiento pasa a ser de pago?

No. Una web estática en GitHub Pages sigue gratis con tu dominio, certificado HTTPS incluido. Solo pagas el dominio al registrador.

¿Cuánto tarda en funcionar el dominio?

Normalmente de minutos a pocas horas, a veces hasta 24 horas mientras se actualiza el DNS. Mientras tanto, la dirección your-name.github.io sigue funcionando.

¿Qué pasa si olvido renovarlo?

La web sigue en GitHub, pero el dominio deja de apuntar a ella y los visitantes ven un error. Activa la renovación automática y regístralo con un correo que leas.
