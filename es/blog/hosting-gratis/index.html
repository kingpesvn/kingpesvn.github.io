Hosting gratis: una web activa 24/7 y con HTTPS

¿El hosting gratis sirve a largo plazo? Tipos de alojamiento gratuito, qué es HTTPS, sus límites y cómo tener la web de tu negocio activa 24/7.

Además del dominio, una web necesita un sitio donde vivir: el hosting. Muchos negocios se preguntan si el hosting gratis dura, si va lento, si mete anuncios o si tiene HTTPS. Esta guía explica en breve los tipos de alojamiento gratuito, los límites que conviene conocer y cómo tener tu web activa 24/7 sin pagar.

Resumen rápido, 5 cosas que saber:

  1. Qué es el hosting
  2. Tipos de hosting gratis

1. ¿Qué es el hosting?

El hosting es un servidor que guarda los archivos de tu web y los envía al navegador cada vez que alguien abre una página. Si el dominio es la dirección, el hosting es la casa. Sin hosting nadie puede entrar, aunque tengas dominio.

Detrás de cada web hay un servidor funcionando día y noche. Foto: rawpixel (CC0).

La web de un negocio pequeño es sobre todo texto, fotos y botones de contacto, así que no necesita un servidor potente.

2. Tipos de hosting gratis

Hay tres tipos principales:

  • Creadores de webs con alojamiento (Wix, Google Sites…): te registras y ya estás online, pero el plan gratis suele usar subdominio y algunos ponen anuncios.
  • Hosting estático gratis (GitHub Pages, Cloudflare Pages, Netlify…): para webs que no ejecutan código en el servidor, como presentaciones, cartas y listas de precios. Rápido y estable.
  • Planes de hosting gratis tradicionales: poco espacio, a menudo con anuncios o que desaparecen al acabar la promoción.

Para un negocio pequeño, el alojamiento estático suele ser la opción más duradera.

3. ¿Qué es HTTPS y por qué lo necesitas?

El HTTPS cifra los datos entre el navegador y tu web y se ve como un candado en la barra de direcciones. Sin él, el navegador marca la web como «No seguro» y el cliente puede irse antes de ver tus productos.

El HTTPS es como un candado: el cliente no ve cómo funciona, pero nota enseguida si falta. Foto: Bich Tran (CC0).

Hoy muchos proveedores emiten certificados HTTPS gratis que se renuevan solos; no pagues de más solo por el candado.

4. «Activa 24/7» y sus límites

El hosting estático guarda copias de tu web en servidores de todo el mundo, así que sigue abierta aunque falle uno. A cambio hay límites; por ejemplo, según la documentación de GitHub en el momento de escribir, GitHub Pages:

  • Limita el tamaño del sitio a unos 1 GB y el tráfico a unos 100 GB al mes, más que suficiente para un negocio pequeño.
  • No está pensado para webs cuyo fin principal sea cobrar pagos online; sirve para mostrar productos y recibir pedidos por mensaje o formulario.
  • Tras editar, pueden pasar unos minutos hasta que se vea la versión nueva.

5. ¿Dónde se alojan las webs de Kingpes?

Al pulsar Publicar, Kingpes sube tu web a GitHub Pages en tu propia cuenta gratuita de GitHub. La dirección es del tipo usuario.github.io/tienda, el HTTPS se activa solo y puedes conectar tu propio dominio cuando quieras.

La web está en tu cuenta: sigue siendo tuya y no quedas atado a un proveedor.

Preguntas frecuentes

¿El hosting gratis es seguro?

Depende. El alojamiento estático de grandes empresas como GitHub Pages tiene HTTPS y funciona estable; los planes gratis de origen dudoso suelen meter anuncios o cerrar de golpe.

¿Dónde se alojan las webs de Kingpes?

En GitHub Pages, dentro de tu propia cuenta gratuita de GitHub. La dirección es del tipo usuario.github.io/tienda y el HTTPS se activa solo.

¿Hay que pagar por el HTTPS?

No. Muchos proveedores emiten certificados gratis que se renuevan solos; con Kingpes el HTTPS sigue activo aunque conectes tu dominio.

¿Puedo vender online con hosting gratis?

Sí para mostrar productos y recibir pedidos por chat, teléfono o Google Forms. El pago online suele requerir servidor y plan de pago.
