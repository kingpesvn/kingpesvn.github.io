Crear web en WordPress gratis: ¿vale la pena?

¿Se puede crear web en WordPress gratis? WordPress.com frente a .org, costos ocultos, mantenimiento y cuándo un negocio pequeño debería elegir otra vía.

Por Kingpes · Publicado 6 de noviembre de 2026 · 3 min de lectura

WordPress aparece siempre que alguien pregunta dónde hacer una web. Pero ¿crear web en WordPress gratis es de verdad gratis y le conviene a un negocio pequeño? Esta guía explica los dos tipos de WordPress, los costos que pocos mencionan al inicio y el mantenimiento mensual, para que decidas si usarlo o elegir algo más ligero.

En resumen, 5 cosas que saber:

  1. Hay dos WordPress distintos
  2. El plan gratis de WordPress.com tiene límites
  3. WordPress autoalojado: software gratis, funcionar cuesta
  4. Mantenimiento: actualizaciones, seguridad, copias
  5. Cuándo usarlo y cuándo no

1. ¿En qué se diferencian WordPress.com y WordPress.org?

WordPress es software de código abierto para webs que usa una gran parte de internet. Hay dos formas: WordPress.com, un servicio listo con registro, y WordPress.org, donde descargas el software para instalarlo en tu propio hosting.

Antes de elegir, anota qué debe hacer tu web: vender, reservar o solo presentar. Foto: Glenn Carstens-Peters (CC0).

Ambas difieren mucho en costo y esfuerzo, así que “WordPress gratis” suele ser solo media verdad.

2. ¿Qué limita el plan gratis de WordPress.com?

El plan gratis te da una web con dirección tipo tutienda.wordpress.com. Según los precios al escribir esto, suele mostrar anuncios de la plataforma, no permite dominio propio ni instalar plugins extra como una tienda completa.

Para quitar anuncios, usar tu dominio o vender bien necesitas un plan de pago anual. Los planes cambian; revisa los precios actuales.

3. WordPress autoalojado: software gratis, funcionar cuesta

Instalarlo desde WordPress.org da control total, pero pagas hosting y dominio. Según el proveedor, el hosting va de unos pocos a algunas decenas de dólares al mes, y el dominio se paga cada año. Muchos temas y plugins de tienda también son de pago.

WordPress es como una caja de herramientas completa: hace mucho, pero hay que saber usar cada pieza. Foto: Todd Quackenbush (CC0).

Y está el tiempo: elegir tema, instalar plugins, ajustar el móvil, conectar pagos. Para un principiante puede llevar días o requerir contratar a alguien. Mira cuánto cuesta una tienda online para estimar el total.

4. Mantenimiento: actualizaciones, seguridad, copias

Una web WordPress necesita cuidados. El núcleo, el tema y los plugins se actualizan a menudo; dejarlos mucho tiempo la hace más vulnerable.

Actualizar y hacer copias es como cerrar con llave una web WordPress. Foto: Mx. Granger (CC0).

Tareas mensuales: actualizar, revisar que los plugins sigan siendo compatibles, copiar datos, revisar la velocidad. Si no tienes tiempo, pagarás un servicio de mantenimiento.

5. ¿Cuándo conviene WordPress?

Elige WordPress si necesitas un blog con muchos artículos, varios autores o funciones a medida como membresías o stock conectado. Ahí el mantenimiento compensa.

No hace falta si solo quieres que el cliente vea productos y precios, reserve y envíe pedidos. Un negocio que empieza quiere su web hoy, no un curso de hosting.

Una opción más ligera para negocios pequeños

Las plantillas por sector ya traen venta o reservas, sin plugins ni actualizaciones que gestionar. Por ejemplo, la plantilla de clases particulares calcula la cuota y reserva la clase de prueba; la plantilla de tienda de videojuegos tiene carrito y tasador de usados.

Preguntas frecuentes

¿WordPress es realmente gratis?

El software sí. Pero para funcionar necesita hosting y dominio, que suelen pagarse; el plan gratis de WordPress.com tiene límites y anuncios.

¿Se puede usar WordPress sin programar?

Sí con el editor de bloques, pero instalar, elegir plugins, actualizar y resolver errores requiere algo de conocimiento técnico o ayuda.

¿Es fácil hackear un WordPress?

Al ser tan popular, recibe muchos intentos. Actualizar, usar plugins de confianza y hacer copias reduce mucho el riesgo; el problema es el abandono.

¿Qué elige un negocio pequeño que empieza?

Si basta con que el cliente vea productos y precios y envíe pedidos, una plantilla lista suele ser más rápida y ligera. WordPress va mejor para blogs grandes o funciones a medida.
