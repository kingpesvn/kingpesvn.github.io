    Tengo cuenta de GitHub
    ¿Aún no tienes cuenta? Regístrate gratis en unos 2 minutos
    1. 1
      Abre la página de registro de GitHub

      Se abre en una pestaña nueva. Tu borrador sigue en esta pestaña.

      Abrir registro ↗
    2. 2
      Escribe tu correo, una contraseña y un nombre de usuario

      El nombre de usuario forma parte de la dirección (tu-cuenta.github.io), así que elige uno corto, como el de tu negocio. GitHub puede pedirte un pequeño rompecabezas para comprobar que eres una persona.

    3. 3
      Confirma tu correo

      Abre tu correo e introduce el código que te envió GitHub. Después vuelve a esta pestaña y pulsa «Iniciar sesión con GitHub».

    GitHub está en inglés: Username = nombre de usuario · Password = contraseña · Continue = continuar · Create account = crear cuenta.
