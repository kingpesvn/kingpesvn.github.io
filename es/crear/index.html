    Apunta tu dominio a la web

    Abre el panel de tu proveedor de dominio (donde lo compraste), ve a DNS y añade los registros de abajo. Borra los registros antiguos con el mismo nombre.

    TipoNombreValor

    Los cambios de DNS tardan de unos minutos a 24 horas. Cuando apunte bien, GitHub activa HTTPS (el candado) en aproximadamente una hora.

  2. 2Conecta GitHub

    Tu sitio se guarda gratis en tu propia cuenta de GitHub. Tú eres el propietario: Kingpes no guarda tu sitio ni tus datos.

    La conexión con GitHub aún se está terminando. Tu borrador está guardado en este navegador. Mientras tanto, puedes descargar tu sitio.
