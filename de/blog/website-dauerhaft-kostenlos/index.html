Website dauerhaft kostenlos: ohne Testphase, ohne Ablauf

So bekommen Sie eine Website dauerhaft kostenlos: Testphase oder echt gratis, 4 Fragen vor der Anmeldung, versteckte Kosten, statische Seiten.

Viele Anbieter versprechen eine kostenlose Website und verlangen nach 14 Tagen Ihre Kreditkarte oder blenden ihre Werbung auf Ihren Seiten ein. Ein kleiner Betrieb braucht eine Website, die ohne Countdown läuft. Dieser Leitfaden zeigt, wie Sie eine Website dauerhaft kostenlos betreiben: der Unterschied zwischen Testphase und echt gratis, was Sie vor der Anmeldung fragen sollten, und zwei neue Vorlagen als Beispiel, ein Möbelhaus und eine Hausverwaltung.

1. „Kostenlos testen“ vs. „dauerhaft kostenlos“

Es gibt drei Arten von „kostenlos“. Die Testphase bietet 7–14 Tage alles, danach zahlen Sie oder die Seite geht offline. Der eingeschränkte Gratis-Tarif läuft unbegrenzt, aber mit Werbung der Plattform, langer Subdomain und gesperrtem Verkauf. Echt kostenlos heißt: kein Ablaufdatum, keine fremde Werbung.

Jede Testphase hat ein Enddatum; prüfen Sie, was danach mit Ihrer Website passiert. Foto: Amitbalani (CC0).

Die zweite Art folgt dem Freemium-Modell: Die Gratisversion zum Kennenlernen, die bezahlte Version reicht fürs Geschäft. Die Bedingungen ändern sich oft; die Angaben hier stimmen zum Zeitpunkt des Schreibens (November 2026).

2. 4 Fragen, bevor Sie auf „Kostenlos anmelden“ klicken

Bevor Sie Stunden mit dem Einpflegen von Produkten verbringen, suchen Sie auf der Preisseite die Antwort auf diese vier Fragen:

  • Wird eine Kreditkarte verlangt? Meist bedeutet das automatische Verlängerung und Abbuchung.
  • Was passiert nach der Testphase? Wird die Seite gesperrt, gelöscht oder auf einen Tarif mit Werbung umgestellt?
  • Zeigt der Gratis-Tarif Namen oder Werbung der Plattform? Ihre Kunden sehen das.
  • Können Sie Ihre Website mitnehmen? Ohne Export bleiben Sie an die Plattform gebunden.

Lässt Sie eine Antwort zögern, wählen Sie gleich einen anderen Weg, bevor Sie Stunden investieren.

3. Häufige versteckte Kosten

Auch wenn der Grundtarif günstig ist, steigt die Summe durch Extras: kostenpflichtige Designs, monatliche Apps für Buchung, Formulare oder Karten, Gebühren pro Bestellung, E-Mail mit eigener Domain und eine Verlängerung im zweiten Jahr, die teurer ist als das erste.

Kleine Monatsbeträge mal 12 zeigen, was die Website wirklich kostet. Foto: stevepb (CC0).

Für eine genaue Rechnung lesen Sie was kostet ein Onlineshop?. Bei einer dauerhaft kostenlosen Website sind Preisliste, Buchung und Formulare schon in der Vorlage, es gibt nichts zuzukaufen.

4. Warum eine statische Website kostenlos bleiben kann

Eine statische Website besteht aus fertigen HTML-Dateien, ohne ständig laufenden Server und ohne Datenbank. GitHub Pages veröffentlicht solche Seiten kostenlos, mit Grenzen von etwa 1 GB Speicher und 100 GB Datenvolumen im Monat, mehr als genug für einen kleinen Laden.

Eine statische Website ist nur Dateien; ohne Monatsserver gibt es keinen Tarif, der abläuft. Foto: Scott Webb (CC0).

Die Kingpes-Vorlagen sind so gebaut. „Lebendige“ Teile wie Filter, Preisrechner oder Terminprüfung laufen im Browser des Besuchers, also weiterhin ohne Server. Sie können die ganze Website auch als .zip herunterladen, aufbewahren oder umziehen.

5. Das Einzige, wofür sich Zahlen lohnt: die eigene Domain

Eine kostenlose Website hat eine Adresse wie ihr-name.github.io. Das funktioniert, aber eine Domain wie ihrladen.de merkt man sich leichter und wirkt auf der Visitenkarte professioneller. Das ist die einzige Ausgabe, die sich lohnt, einmal im Jahr.

Lesen Sie vor dem Kauf kostenlose Domain: sinnvoll für Ihr Geschäft?, um „geschenkte“ Domains zu vermeiden, die nach einem Jahr zurückgehen. Haben Sie eine Domain, verbinden Sie sie einfach mit der Website; das Hosting bleibt kostenlos.

Ein Möbelhaus braucht viele Fotos und Produktseiten; auch die liegen auf einer statischen Website kostenlos. Foto: Justin Schüler (CC0).

Häufige Fragen

Gibt es wirklich eine dauerhaft kostenlose Website?

Ja, wenn es eine statische Website ist, die bei einem langfristig kostenlosen Dienst wie GitHub Pages liegt. Es gibt keinen Server zur Monatsmiete und damit keinen Tarif, der abläuft. Sie zahlen nur für eine eigene Domain.

Reichen die Gratis-Tarife der Baukasten-Anbieter?

Zum Ausprobieren ja, aber meist mit Werbung der Plattform, langer Subdomain und gesperrten Shop-Funktionen. Die Bedingungen ändern sich oft; lesen Sie die Preisseite genau, bevor Sie sich festlegen.

Was, wenn ich später umziehen möchte?

Mit einer Kingpes-Vorlage laden Sie die ganze Website als .zip-Datei herunter. Das sind normale HTML-Dateien, die jeder Webhoster veröffentlichen kann.

Brauche ich für eine kostenlose Website eine Kreditkarte?

Nein. Eine wirklich kostenlose Website fragt nicht nach Karte. Verlangt eine „kostenlose“ Anmeldung Ihre Karte, ist es meist eine Testphase, die sich automatisch verlängert und abbucht.
