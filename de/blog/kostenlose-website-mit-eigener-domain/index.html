Kostenlose Website mit eigener Domain: was kostet das?

So kommen Sie zur kostenlosen Website mit eigener Domain: was gratis bleibt, was jährlich kostet, Domain wählen und kaufen und in 4 Schritten verbinden.

Viele suchen eine kostenlose Website mit Domain und bekommen im zweiten Jahr eine Verlängerungsrechnung, die ein Vielfaches des ersten Jahres beträgt. Dabei ist es einfach: Erstellen und Hosten der Website kann jahrelang gratis bleiben, die Domain kostet dagegen jedes Jahr einen kleinen Betrag. Dieser Leitfaden zeigt, wie Sie eine kostenlose Website mit eigener Domain einrichten: was nichts kostet, wie Sie die Domain wählen und kaufen und mit welchen 4 Schritten Sie sie verbinden.

1. Was ist eine eigene Domain, und warum ist sie nicht gratis?

Eine Domain ist die Adresse, die Kunden eintippen, um Ihre Website zu öffnen, zum Beispiel saltlinefish.com. Sie ist wie eine Hausanschrift: Das Haus (die Website) kann irgendwo stehen, aber die Anschrift merken sich die Leute und Sie drucken sie auf Karten, Tüten und Schilder.

Domains werden von internationalen und nationalen Registrierungsstellen verwaltet. Jeder Name hat für einen Zeitraum nur einen Inhaber, daher zahlen alle Registrierung und jährliche Verlängerung. Dienste mit „Domain für immer gratis“ geben meist eine Subdomain wie shop.plattform.com oder sind nur im ersten Jahr kostenlos.

2. Was ist kostenlos und was kostet Geld?

Eine Website besteht aus drei Teilen, und nur einer kostet Geld:

  • Website erstellen: kostenlos mit einer fertigen Vorlage, Sie tauschen Texte, Preise und Fotos.
  • Hosting: kostenlos für statische Websites auf GitHub Pages, mit HTTPS. Siehe kostenloses Webhosting.
  • Eigene Domain: jährlich an einen Registrar bezahlt.

Ohne eigene Domain läuft die Website trotzdem unter einer Adresse wie your-name.github.io. Sie können so starten, ein paar Wochen testen und die Domain kaufen, wenn der Name des Geschäfts feststeht.

3. Eine einprägsame Domain wählen

Eine gute Domain tippt man nach einmal Hören richtig. Ein paar Regeln:

  • Kurz und möglichst ohne Bindestrich: blaurose.de ist leichter als blau-rose-laden-24h.de.
  • Gleich oder ähnlich wie der Name auf dem Schild und in den sozialen Netzen.
  • Laut vorlesen: Fragt jemand „Wie schreibt man das?“, ändern Sie sie.
  • Endung nach Kundschaft wählen: Länderendung für lokale Kunden, .com für mehrere Länder.

Eine Domain ist wie eine Hausnummer: kurz, klar, auf einen Blick lesbar. Foto: Daniel von Appen (CC0).

Die Verfügbarkeit prüfen Sie direkt beim Registrar. Ist der Wunschname vergeben, ergänzen Sie Ort oder Branche statt einer Zahl.

4. Wo kaufen und auf die Verlängerung achten

Kaufen Sie bei einem akkreditierten Registrar. Eine .com kostet meist 10 bis 20 Euro im Jahr, manche Länderendungen mehr. Preise ändern sich; die Angaben gelten zum Zeitpunkt des Schreibens (November 2026).

Domains werden jährlich bezahlt: Prüfen Sie den Preis ab dem zweiten Jahr, nicht nur das Einstiegsangebot. Foto: Brooke Lark (CC0).

Prüfen Sie vor dem Bezahlen drei Dinge: den Verlängerungspreis im zweiten Jahr, die Gebühr für einen Umzug zu einem anderen Anbieter und ob Inhaber-Datenschutz enthalten ist. Verzichten Sie auf Pakete aus Domain und Hosting, wenn Ihr Hosting schon kostenlos ist. Lesen Sie kostenlose Domain für Geschäfte: lohnt sich das?, warum „geschenkte“ Domains oft Ärger machen.

5. Die Domain in 4 Schritten verbinden

Mit einer Website auf GitHub Pages und einer Domain dauert die Verbindung etwa 10 Minuten:

  1. Domain bei GitHub eintragen: im Repository der Website Settings → Pages öffnen und unter Custom domain eingeben.
  2. DNS-Einträge beim Registrar anlegen: vier A-Einträge, die die Hauptdomain auf GitHub Pages zeigen, und einen CNAME für www auf your-name.github.io.
  3. Auf das DNS warten: meist Minuten bis wenige Stunden.
  4. Enforce HTTPS einschalten: GitHub stellt ein kostenloses Zertifikat aus, im Browser erscheint das Schloss.

Die einzutragenden IP-Adressen stehen in der Dokumentation von GitHub Pages. Bei einem Tippfehler zeigt GitHub in Settings einen DNS-Prüffehler an, den Sie einfach korrigieren.

Häufige Fragen

Bekomme ich eine .com-Domain ganz umsonst?

Praktisch nicht. .com, .net, .de und andere kosten Registrierung und jährliche Verlängerung. Angebote mit „Gratis-Domain“ sind meist nur im ersten Jahr kostenlos oder an deren Hosting gebunden.

Wird das Hosting mit eigener Domain kostenpflichtig?

Nein. Eine statische Website auf GitHub Pages bleibt mit eigener Domain kostenlos, inklusive HTTPS-Zertifikat. Sie bezahlen nur die Domain beim Registrar.

Wie lange dauert es, bis die Domain funktioniert?

Meist Minuten bis wenige Stunden, manchmal bis zu 24 Stunden, bis das DNS aktualisiert ist. Die alte Adresse your-name.github.io funktioniert so lange weiter.

Was passiert, wenn ich die Verlängerung vergesse?

Die Website liegt weiter auf GitHub, aber die Domain zeigt nicht mehr darauf und Besucher sehen einen Fehler. Schalten Sie die automatische Verlängerung ein und nutzen Sie eine E-Mail, die Sie lesen.
