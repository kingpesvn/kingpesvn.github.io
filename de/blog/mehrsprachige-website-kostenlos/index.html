Mehrsprachige Website kostenlos erstellen: für Läden

Mehrsprachige Website kostenlos erstellen: Sprachen nach Land hinzufügen, Preise in Landeswährung, eigene Adresse je Sprache und Tipps fürs Übersetzen.

Touristen, Zugezogene aus dem Ausland in Ihrer Nähe und Partner in anderen Ländern möchten Ihre Website in ihrer Sprache lesen. Viele Ladeninhaber glauben, für eine zweisprachige Seite brauche man einen Programmierer. Tatsächlich können Sie eine mehrsprachige Website kostenlos erstellen, mit einer fertigen Vorlage: Jede Sprache ist eine eigene Version, mit Preisen in der Landeswährung. Dieser Ratgeber erklärt, wie es geht und was Sie vor dem Veröffentlichen prüfen sollten.

Kurz zusammengefasst, 5 Punkte:

  1. Wann sich eine mehrsprachige Website lohnt
  2. Sprachen nach Land hinzufügen
  3. Preise und Währung je Land
  4. Inhalte richtig übersetzen
  5. Wie Besucher die richtige Sprache finden

1. Wann lohnt sich eine mehrsprachige Website?

Sobald Kunden kein Deutsch lesen: Ferienwohnungen, Reiseveranstalter, Cafés in Urlaubsorten, Läden mit Versand ins Ausland, Übersetzungsbüros. Für den Anfang reicht meist eine englische Version; Französisch, Polnisch oder Chinesisch kommen dazu, wenn diese Kunden häufiger werden.

Ausländische Kunden vertrauen Läden, die ihre Sprache sprechen, vom Schild bis zur Website. Foto: Hippietrail (CC0).

Sie müssen nicht alles auf einmal übersetzen. Beginnen Sie mit dem Wichtigsten: Vorstellung, Preise, Öffnungszeiten und Kontakt.

2. Sprachen nach Land hinzufügen

Öffnen Sie im Kingpes-Editor den Tab Sprachen und wählen Sie das Land Ihrer Kunden. Sprache und Währung werden automatisch gesetzt, etwa Koreanisch und Won für Südkorea. Bei mehrsprachigen Ländern wie Kanada oder der Schweiz ändern Sie Sprache und Währung in den erweiterten Optionen.

Jede Sprache hat eine eigene Adresse, zum Beispiel /de/ für Deutsch und /us/ für Englisch. Wählen Sie die Sprache, die Sie bearbeiten, und die übrigen Tabs und die Vorschau wechseln mit.

3. Preise und Währung je Land

Fremdsprachige Versionen zeigen Preise in der Währung des Landes. Beim Hinzufügen einer Sprache trägt der Editor den Tageskurs ein; Sie wählen die Rundung oder geben Preise pro Artikel von Hand ein.

Preise in einer vertrauten Währung ersparen Kunden das Umrechnen im Kopf. Foto: Nihon Coin Auction (gemeinfrei).

Setzen Sie Preise für Bestseller von Hand: Eine exakte Umrechnung passt nicht immer zum Preisniveau im anderen Land.

4. Wie übersetzt man Inhalte richtig?

Beim Hinzufügen einer Sprache wird der Text der englischen Version zum Bearbeiten kopiert; nichts wird automatisch übersetzt. Maschinelle Übersetzung liefert schnell einen Entwurf, irrt sich aber oft bei Gerichtnamen, Einheiten und Tonfall. Lassen Sie mindestens Preise, Öffnungszeiten und Bedingungen von jemandem prüfen, der die Sprache spricht.

Knöpfe und Menüs der Vorlagen gibt es bereits in vielen Sprachen; Sie übersetzen vor allem die eigenen Inhalte Ihres Ladens. Sprachen, die von rechts nach links geschrieben werden, etwa Arabisch, werden noch nicht vollständig unterstützt.

5. Wie finden Besucher die richtige Sprache?

Die Hauptadresse Ihrer Website leitet Besucher nach ihrer Browsersprache weiter: Ein koreanischer Kunde, der den Link öffnet, landet auf der koreanischen Version. Die Versionen sind mit hreflang-Tags verknüpft, damit Google erkennt, dass es dieselbe Seite in mehreren Sprachen ist.

Besucher können über die Regionsschaltfläche oben auf der Seite wechseln und sehen einen Hinweis, Preise in ihrer Währung anzuzeigen, wenn sie in der falschen Version landen.

Wie fange ich an?

Dieses Gebäude in Wales ist walisisch und englisch beschriftet. Bei Websites ist es genauso: mit zwei Sprachen anfangen, weitere ergänzen, wenn Kunden kommen. Foto: Michael (CC0).

Häufige Fragen

Kostet eine mehrsprachige Website extra?

Bei Kingpes nicht. Jede Sprache ist eine Version derselben Website und wird gemeinsam in einem Schritt auf dem kostenlosen GitHub Pages veröffentlicht.

Übersetzt Kingpes die Inhalte automatisch?

Nein. Beim Hinzufügen einer Sprache wird der Text der englischen Version als Ausgangspunkt kopiert. Übersetzen Sie selbst, fragen Sie jemanden, der die Sprache spricht, oder nutzen Sie ein Übersetzungstool und lassen Sie es gegenlesen.

Wie werden Preise in anderen Sprachen berechnet?

Jede Sprache hat eine Währung. Der Editor trägt den Tageskurs ein, und Sie können Preise pro Artikel von Hand eingeben, wenn Sie runde Beträge möchten.

Welche Sprache sehen Besucher?

Die Hauptadresse leitet Besucher zur Version in ihrer Browsersprache. Über die Regionsschaltfläche oben auf der Seite können sie trotzdem wechseln.
