    Ich habe ein GitHub-Konto
    Noch kein Konto? In etwa 2 Minuten kostenlos registrieren
    1. 1
      GitHub-Registrierung öffnen

      Sie öffnet sich in einem neuen Tab. Ihr Entwurf bleibt in diesem Tab.

      Registrierung öffnen ↗
    2. 2
      E-Mail, Passwort und Benutzernamen eingeben

      Der Benutzername wird Teil der Adresse (ihr-konto.github.io). Wählen Sie also einen kurzen Namen wie den Ihres Geschäfts. GitHub fragt eventuell ein kleines Rätsel ab, um zu prüfen, dass Sie ein Mensch sind.

    3. 3
      E-Mail bestätigen

      Öffnen Sie Ihre E-Mails und geben Sie den Code von GitHub ein. Kehren Sie dann zu diesem Tab zurück und klicken Sie auf „Mit GitHub anmelden“.

    GitHub ist auf Englisch: Username = Benutzername · Password = Passwort · Continue = weiter · Create account = Konto erstellen.
