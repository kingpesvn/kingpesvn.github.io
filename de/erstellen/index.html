Website online stellen

  1. 1Adresse wählen

    Domain auf die Website zeigen lassen

    Öffnen Sie die Verwaltung Ihres Domain-Anbieters (wo Sie sie gekauft haben), gehen Sie zu DNS und fügen Sie die Einträge unten hinzu. Löschen Sie alte Einträge mit gleichem Namen.

    TypNameWert

    DNS-Änderungen dauern einige Minuten bis 24 Stunden. Sobald die Domain richtig zeigt, aktiviert GitHub HTTPS (das Schloss) in etwa einer Stunde.

  2. 2GitHub verbinden

    Ihre Website wird kostenlos in Ihrem eigenen GitHub-Konto gespeichert. Sie gehört Ihnen: Kingpes speichert weder Ihre Website noch Ihre Daten.

    Die Verbindung mit GitHub wird gerade fertiggestellt. Ihr Entwurf ist in diesem Browser gespeichert. Bis dahin können Sie Ihre Website herunterladen.
