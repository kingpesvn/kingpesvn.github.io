นำเว็บไซต์ขึ้นออนไลน์

  1. 1เลือกที่อยู่เว็บ

    ชี้โดเมนมาที่เว็บไซต์

    เปิดหน้าจัดการโดเมน (ที่คุณซื้อ) ไปที่ DNS แล้วเพิ่มเรคคอร์ดด้านล่าง ลบเรคคอร์ดเก่าที่ชื่อซ้ำ

    ประเภทชื่อค่า

    การเปลี่ยน DNS อาจใช้เวลาตั้งแต่ไม่กี่นาทีถึง 24 ชั่วโมง เมื่อชี้ถูกต้องแล้ว GitHub จะเปิด HTTPS (แม่กุญแจ) ภายในราว 1 ชั่วโมง

  2. 2เชื่อมต่อ GitHub

    เว็บไซต์ถูกเก็บฟรีในบัญชี GitHub ของคุณเอง คุณเป็นเจ้าของ Kingpes ไม่ได้เก็บเว็บไซต์หรือข้อมูลของคุณ

    การเชื่อมต่อ GitHub กำลังพัฒนาให้เสร็จ ฉบับร่างของคุณบันทึกไว้ในเบราว์เซอร์นี้แล้ว ระหว่างนี้คุณดาวน์โหลดเว็บไซต์ไปก่อนได้
