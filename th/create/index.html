นำเว็บไซต์ขึ้นออนไลน์

  1. 1เลือกที่อยู่เว็บ

  2. 2เชื่อมต่อ GitHub

    เว็บไซต์ถูกเก็บฟรีในบัญชี GitHub ของคุณเอง คุณเป็นเจ้าของ Kingpes ไม่ได้เก็บเว็บไซต์หรือข้อมูลของคุณ

    มีบัญชี GitHub แล้ว
    ยังไม่มีบัญชีใช่ไหม สมัครฟรีได้ในประมาณ 2 นาที
    1. 1
      เปิดหน้าสมัคร GitHub

      จะเปิดในแท็บใหม่ ฉบับร่างยังอยู่ในแท็บนี้

      เปิดหน้าสมัคร ↗
    2. 2
      กรอกอีเมล รหัสผ่าน และชื่อผู้ใช้

      ชื่อผู้ใช้จะเป็นส่วนหนึ่งของที่อยู่เว็บ (your-account.github.io) ควรตั้งสั้น ๆ คล้ายชื่อร้าน GitHub อาจให้ทำปริศนาเล็ก ๆ เพื่อยืนยันว่าเป็นคนจริง

    3. 3
      ยืนยันอีเมล

      เปิดอีเมลแล้วกรอกรหัสที่ GitHub ส่งมา จากนั้นกลับมาที่แท็บนี้และกด "เข้าสู่ระบบด้วย GitHub"

    หน้าจอ GitHub เป็นภาษาอังกฤษ: Username = ชื่อผู้ใช้ · Password = รหัสผ่าน · Continue = ถัดไป · Create account = สร้างบัญชี

    การเชื่อมต่อ GitHub กำลังพัฒนาให้เสร็จ ฉบับร่างของคุณบันทึกไว้ในเบราว์เซอร์นี้แล้ว ระหว่างนี้คุณดาวน์โหลดเว็บไซต์ไปก่อนได้
