把网站发布上线

  1. 1选择网址

  2. 2连接 GitHub

    网站免费保存在你自己的 GitHub 账号里。网站归你所有，Kingpes 不保管你的网站或数据。

    我已有 GitHub 账号
    还没有账号？约 2 分钟即可免费注册
    1. 1
      打开 GitHub 注册页面

      会在新标签页打开，草稿仍保留在这个标签页。

      打开注册页面 ↗
    2. 2
      填写邮箱、密码和用户名

      用户名会成为网址的一部分（your-account.github.io），建议取一个像店名的简短名字。GitHub 可能会让你完成一个小验证拼图。

    3. 3
      验证邮箱

      打开邮箱，输入 GitHub 发来的验证码。完成后回到这个标签页，点击“用 GitHub 登录”。

    GitHub 界面是英文的：Username = 用户名 · Password = 密码 · Continue = 继续 · Create account = 创建账号。
