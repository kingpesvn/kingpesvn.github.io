    类型名称值

    DNS 生效需要几分钟到24小时。指向正确后,GitHub 会在约1小时内自动开启 HTTPS(小锁)。

    网站免费保存在你自己的 GitHub 账号里。网站归你所有，Kingpes 不保管你的网站或数据。
