小企业免费建网站：网站必备的6个部分

小企业如何免费建网站：客户想看到的6个部分，从服务、价格、服务范围到自动报价和预约，附2个示例模板。

很多小企业老板觉得网站是大公司的事：花钱、要请人做、难更新。其实客户在打电话之前，都会先上网搜索。本文介绍小企业如何免费建网站，讲清客户需要看到的6个部分，并用两个新模板举例：一家花园设计工作室和一位婚礼摄影师。

快速总结，网站必备的6个部分：

  1. 一句话说清您做什么、在哪里
  2. 服务和参考价格
  3. 真实作品照片
  4. 自动报价或档期查询
  5. 服务范围、营业时间和联系方式
  6. 客户评价、常见问题和预约按钮

1. 一句话说清您做什么、在哪里

访客只会看几秒钟。第一行要回答：您做什么、在哪个城市、和别人有什么不同。花园设计模板的开头是“波特兰花园设计与施工”，再配上3个数字：完成的花园数量、植物保活期和评分。

页面顶部放一张好的作品照片，比一大段介绍更有说服力。图片：Matt Bango（CC0）

在大多数国家，中小企业占企业总数的绝大部分，客户总有很多选择。清楚的第一句话能让他们留在您的页面上。

2. 服务和参考价格

哪怕只写“起价……”，也能筛选出预算合适的客户，减少问价消息。花园模板按面积标价，并按国家自动切换平方英尺和平方米；婚礼摄影模板按小时列出套餐，最受欢迎的套餐有标记。记得注明价格是否含税。

把服务分组：设计、施工、养护；或拍摄套餐和附加服务。每项服务用一句话说明客户能得到什么。

3. 真实作品照片

真实照片比网上的示例图更让人信任。花园模板有施工前后对比照，拖动滑块即可比较；婚礼摄影模板为每场婚礼准备相册，可全屏浏览。

像这家面包店一样，商品照片配上价格，客户立刻知道花多少钱能得到什么。图片：Andy Li（CC0）

挑选最好的6到9张就够了。用手机拍也可以，只要光线充足、画面端正；技巧见用手机拍产品照片。

4. 自动报价或档期查询

这是让小企业网站和一张传单完全不同的部分。花园模板有预算计算器：输入院子面积，选择装修档次、铺装和草坪比例，勾选自动灌溉、灯光和水景，立即得出价格区间。婚礼摄影师模板让新人选择婚期，看是否有档，再自己组合套餐，得出总价和定金。

像婚礼拍摄这样按日期预约的服务，第一个问题永远是“那天有档吗”。图片：Matt Bango（CC0）

计算结果会自动填进咨询表，您收到的消息里已经有面积、预算或婚期。详情请看婚礼摄影师网站一文。

5. 服务范围、营业时间和联系方式

服务型企业要写清楚在哪里接单：区县列表，或方圆多少公里。再加上营业时间、地图、电话、邮箱和消息按钮。模板会按您所在的时区自动显示“营业中”或“已打烊”。

在编辑器里更新营业时间、价格和空档，每周只要几分钟。图片：Photo Mix（CC0）

别忘了把店铺放到地图上：参考把店铺添加到 Google 地图，在资料里附上网站链接；面向国内客户的也可以登记高德地图和大众点评。

6. 客户评价、常见问题和预约按钮

3到5条真实评价，写明姓名和使用的服务，比一个笼统的星级更可信。常见问题提前回答客户常问的事：价格包含什么、定金怎么付、多久完成。

预约或询价按钮放在顶部栏，手机上再放一个底部栏。如果需要更完整的公司介绍，可以看看免费公司网站模板。

常见问题

已经有社交账号，小企业还需要网站吗？

需要。社交账号适合发动态，网站则是客户在搜索中找到您、查看价格和服务范围、无需私信就能预约的地方。两者一起用，网站是您固定的地址。

免费网站有什么限制？

使用 Kingpes 模板，网站免费托管在 GitHub Pages，没有广告，也不会过期。主要限制是内容需要自己更新；如果要用自己的域名，每年需要支付域名费用。

不会写代码能做吗？

能。选一个适合您行业的模板，在编辑器里改文字、价格和照片，在电脑和手机上预览，然后发布。不需要安装任何软件。

不在网上卖货的服务型企业，网站有什么用？

服务型客户想知道您做什么、大概多少钱、能不能到他们那里、什么时候有空。网站回答这四个问题，并把需求发到您的微信、邮箱或在线表单。
