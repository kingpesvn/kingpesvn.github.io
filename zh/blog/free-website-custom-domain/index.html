免费网站绑定自己的域名：要花多少钱？

1. 什么是自己的域名？为什么不可能免费？

域名是顾客输入来打开网站的地址，例如 saltlinefish.com。它就像门牌号：房子（网站）可以在任何地方，但顾客记住、印在名片、袋子和招牌上的是这个地址。

域名由国际和各国的注册机构管理，每个名字在一段时间内只有一个所有者，所以人人都要付注册费和每年的续费。号称“永久免费域名”的服务，通常给的是 shop.platform.com 这样的子域名，或者只有第一年免费。

2. 哪些免费，哪些要付钱？

一个网站由三部分组成，只有一部分要花钱：

  • 制作网站：用现成模板免费，只需替换文字、价格和照片。
  • 主机（托管）：静态网站放在 GitHub Pages 上免费，自带 HTTPS。参见免费主机。
  • 自己的域名：每年付给域名注册商。

没有自己的域名，网站照样能在 your-name.github.io 这样的地址运行。您可以先这样开始，试营业几周，等店名确定后再买域名。

3. 挑一个顾客记得住的域名

好域名是听一遍就能输对的域名。几条原则：

  • 短，尽量不用连字符：lanmeigui.com 比 lan-mei-gui-shop-24h.com 好记。
  • 与招牌和社交媒体上的名字一致或相近。
  • 念给别人听：如果对方问“怎么拼？”，就换一个。
  • 按顾客选后缀：本地顾客用国家后缀，跨境销售用 .com。

域名就像门牌号：要短、要清楚，一眼就能看懂。照片：Daniel von Appen（CC0）

在注册商网站上可以直接查询名字是否可用。想要的名字被占用时，加上地区或行业，而不是加数字。

4. 在哪里买，注意续费价格

在有资质的注册商购买域名。.com 一般每年约 60 到 120 元人民币，部分国家后缀更贵。价格因商家和时间而异，本文信息以撰写时（2026 年 11 月）为准。

域名按年计费：不要只看首年优惠，要看第二年起的续费价。照片：Brooke Lark（CC0）

付款前看三点：第二年的续费价、转出到其他商家的费用、是否包含隐私保护。如果主机已经免费，就不需要“域名加主机”套餐。为什么“赠送的免费域名”容易出问题，请看免费域名适合店铺吗？。

5. 4 步绑定域名

有了 GitHub Pages 上的网站和一个域名，绑定大约只要 10 分钟：

  1. 在 GitHub 填写域名：在网站仓库打开 Settings → Pages，在 Custom domain 中输入域名。
  2. 在注册商添加 DNS 记录：添加 4 条 A 记录，把根域名指向 GitHub Pages；再添加一条 CNAME，把 www 指向 your-name.github.io。
  3. 等待 DNS 生效：通常几分钟到几小时。
  4. 开启 Enforce HTTPS：GitHub 会免费签发证书，浏览器显示小锁。

需要填写的 IP 地址在 GitHub Pages 文档中可以找到。若输错一个字符，Settings 页面会提示 DNS 检查错误，改正即可。

常见问题

能完全免费拿到 .com 域名吗？

基本不能。.com、.net、.cn 都要付注册费和每年的续费。“免费域名”通常只是第一年免费，或者必须同时购买他们的主机。

绑定自己的域名后，主机要收费吗？

不用。放在 GitHub Pages 上的静态网站绑定自己的域名后仍然免费，包括 HTTPS 证书。您只需向注册商支付域名费用。

设置后多久能访问？

通常几分钟到几小时，DNS 生效有时需要 24 小时。在此期间，原来的 your-name.github.io 地址照常可用。

忘了续费会怎样？

网站仍在 GitHub 上，但域名不再指向它，顾客打不开。请开启自动续费，并用您常看的邮箱注册。
