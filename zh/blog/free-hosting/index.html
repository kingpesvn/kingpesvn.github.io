免费网站托管：全天候运行、带 HTTPS 的网站

除了域名，网站还需要一个“住处”，也就是托管。很多店主会问免费网站托管能不能长期用、会不会很慢、有没有广告、支不支持 HTTPS。本文简单介绍免费托管的类型、需要了解的限制，以及如何不花钱让网站全天候在线。

1. 托管是什么？

托管就是一台服务器，存放网站文件，每次有人打开页面时把文件发送给浏览器。如果域名是门牌地址，托管就是房子。没有托管，就算有域名也没人能访问。

每个网站背后都有一台日夜运行的服务器。图片：rawpixel（CC0）

小店网站主要是文字、图片和联系按钮，不需要很强的服务器。

2. 免费托管的类型

主要有三种：

  • 自带托管的建站平台（Wix、Google 协作平台等）：注册就能上线，但免费版通常用子域名，有的会插广告。
  • 免费静态托管（GitHub Pages、Cloudflare Pages、Netlify 等）：适合不需要在服务器上运行程序的网站，如介绍页、菜单、价目表。快速稳定。
  • 传统免费主机方案：空间小，常插广告，或促销结束就停用。

对小店来说，静态托管通常是最持久的选择。

3. HTTPS 是什么，为什么需要？

HTTPS会加密浏览器与网站之间的数据，地址栏显示一把锁。没有 HTTPS，浏览器会标注“不安全”，顾客可能还没看商品就离开了。

HTTPS 就像一把锁：顾客看不到它怎么工作，但缺了马上会发现。图片：Bich Tran（CC0）

现在很多服务商都免费签发并自动续期 HTTPS 证书，不必只为这把锁额外付钱。

4. “全天候在线”与限制

静态托管会把网站副本放在全球多台服务器上，一台出故障网站仍可访问。相应也有限制，例如根据撰写时 GitHub 的文档，GitHub Pages：

  • 网站容量上限约 1 GB，每月流量约 100 GB，对小店绰绰有余。
  • 不适合以在线支付交易为主要目的的网站，适合展示商品并通过消息或表单接单。
  • 修改后可能要几分钟顾客才能看到新内容。

网站在你自己的账号里，所有权归你，也不会被某一家服务商绑住。

Kingpes 的网站放在哪里？

HTTPS 需要付费吗？
