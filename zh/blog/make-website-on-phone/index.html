用手机做网站，不用电脑：6个步骤

用手机做网站的6个步骤：选模板、改文字、用相机拍商品照片、加上电话和下单方式，再免费发布上线，全程不用电脑，也不用安装应用。

整天忙着卖货，店里没有电脑，却希望顾客能在 Google 上找到你？你完全可以用手机做网站，就用平时回复顾客消息的那部手机。不用装应用，不用写代码，第一版大约 10–15 分钟。本文一步步说明，并附上在小屏幕上操作的小技巧。

快速总结，用手机做网站的 6 个步骤：

  1. 用浏览器打开模板库
  2. 选对行业的模板并预览
  3. 修改店名、文字和颜色
  4. 用相机拍商品照片
  5. 加上电话、WhatsApp 和下单方式
  6. 免费发布网站

1. 用浏览器打开模板库

如今的智能手机足以用来做网站，前提是工具专为小屏幕设计。打开 Chrome 或 Safari，进入免费网站模板库。这一步不需要下载应用，也不用注册。

本文每一步都能单手在手机上完成。图片：Dayne Topkin（CC0）

第一次操作建议用 Wi-Fi，预览和上传照片会更快。

2. 选对行业的模板并预览

在搜索框输入你的行业，或按主题筛选。点预览打开真实运行的网站，这就是顾客在手机上看到的样子。喜欢就点使用模板。

本周两款新模板：裁缝店模板可按场合筛选款式并预约量身；修表修鞋模板有“出了什么问题？”，顾客自己就能找到对应服务。两款都能完全在手机上修改。

3. 修改店名、文字和颜色

手机上的编辑器分为编辑面板和预览两部分。顶部正中的电脑 / 手机按钮，让你拿着手机也能查看两种屏幕尺寸。

  • 内容：店名、口号、介绍
  • 外观：主色、背景色、Logo
  • 每次修改，预览都会立刻更新

在手机上打长文字比较累，可以先在备忘录里写好介绍再粘贴进去。

4. 用相机拍商品照片

这是手机比电脑更方便的地方。添加商品或更换照片时，点拍照就能直接打开后置相机。照片会自动缩小，网站打开更快，不需要再调整。

在编辑器里直接拍，不用把照片传到电脑。图片：Gabriel Santiago（CC0）

靠近窗户、用素色背景、手机拿正。另见用手机拍商品照片的技巧。裁缝店可以逐卷拍布料，修鞋店放上修前修后的对比照，更能让顾客信任手艺。

5. 加上电话、WhatsApp 和下单方式

在联系方式里填写电话、WhatsApp、地址和营业时间，地图会按地址自动显示。想让订单更整齐，开启通过 Google 表单接单：每张订单变成 Google 表格里的一行，用手机也能查看。

6. 免费发布网站

点发布网站，起一个网站名，再用免费的 GitHub 账号登录。还没有账号可以在登录页直接注册，手机上也能完成。大约 1–2 分钟后，网站就以 HTTPS 网址全天在线。

小摊位也值得有个网站，让顾客来之前先看价格。图片：Wikimedia Commons（CC0）

上线后，把链接分享到微信和社交平台，并在柜台贴上二维码。

用手机做网站要注意什么？

  • 草稿保存在这台手机的浏览器里。 换设备时点下载保存 .zip，再用从文件打开载入。
  • 修改长价目表时，把手机横过来更好看清。
  • 做到一半时不要清除浏览器数据。

不是每个工具都能在手机上编辑。例如 Google 帮助页面写明，Google Sites 需要用电脑编辑；可参考 Kingpes、Google Sites 与 Wix 对比来选择。

常见问题

用手机做网站需要安装应用吗？

不需要。用 Chrome 或 Safari 等自带浏览器打开 Kingpes，选好模板就能直接在页面上修改。

旧手机可以做吗？

可以，只要浏览器还在更新。新手机预览更流畅，但改文字和照片的步骤是一样的。

手机上的草稿会丢吗？

草稿保存在这台手机的浏览器里。想在别的设备继续，点“下载”保存 .zip 文件，再用“从文件打开”载入。

用手机发布网站要花钱吗？

不用。需要一个免费的 GitHub 账号，网址和 HTTPS 都免费。只有自有域名需要按年付费。
