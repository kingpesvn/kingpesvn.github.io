1. “免费试用”和“永久免费”的区别

你会遇到三种“免费”。免费试用：7–14 天内功能全开，到期后要付费，否则网站下线。有限制的免费套餐：可以一直用，但带平台广告、很长的二级地址，销售功能被锁。真正免费：没有到期日，页面上也没有广告。

试用总有结束的一天，务必看清那天之后网站会怎样。图片：Amitbalani（CC0）

第二种属于免费增值模式：免费版让你熟悉，付费版才够做生意。各平台的条款经常变化，本文内容以撰写时（2026 年 11 月）为准。

2. 点“免费注册”前的4个问题

在花时间录入商品之前，先在价格页找到这四个问题的答案：

  • 要不要绑定银行卡？ 绑卡通常意味着会自动续费扣款。
  • 试用结束后网站怎么样？ 被锁、被删，还是变成带广告的套餐？
  • 免费套餐会显示平台名称或广告吗？ 你的顾客也会看到。
  • 网站能带走吗？ 如果无法导出，你就被绑在这个平台上。

只要有一个答案让你犹豫，就趁早换别的方式，别等录入了好几个小时再后悔。

3. 常见的隐藏费用

即使基础套餐便宜，加上各种附加项总价也会变高：付费主题、按月收费的预约、表单、地图应用，每笔订单的交易手续费，企业邮箱，以及第二年比第一年更贵的续费价。

每月的小额费用乘以 12，才看得出网站真正花多少钱。图片：stevepb（CC0）

想仔细算一算，可以看做一个网店网站要多少钱。永久免费的网站把价格表、预约、表单等功能都做进了模板，不需要另外购买。

4. 静态网站为什么能长期免费

静态网站是一组做好的 HTML 文件，不需要全天运行的服务器，也不需要数据库。GitHub Pages 可以免费托管这类网站，空间约 1 GB、每月流量约 100 GB，对小店来说绰绰有余。

静态网站就是一些文件，没有按月租的服务器，也就没有会到期的套餐。图片：Scott Webb（CC0）

Kingpes 模板就是这样做的。筛选、算价、查日期等“会动”的部分在顾客的浏览器里运行，同样不需要服务器。你还能把整个网站下载成 .zip 保存或搬到别处。

5. 唯一值得花钱的：自己的域名

免费网站的地址类似 your-name.github.io。能用，但 yourstore.com 这样的自有域名更好记，印在名片上也更专业。这是唯一值得付的费用，按年付。

购买前先读免费域名适合店铺吗？，避开一年后被收回的“免费”域名。买好域名后只需指向网站，托管依然免费。

常见问题

永久免费的网站真的存在吗？

存在。只要是静态网站，并放在 GitHub Pages 这类可以长期免费使用的地方，就没有按月租用的服务器，也就没有会到期的套餐。只有想用自己的域名时才需要付费。

建站平台的免费套餐够用吗？

试用够了，但通常会显示平台广告、使用很长的二级地址，并锁住销售功能。条款经常变化，选择前请仔细看价格页。

以后想搬到别处怎么办？

用 Kingpes 模板，可以把整个网站下载成 .zip 文件。都是普通的 HTML 文件，放到任何主机都能用。

做免费网站需要绑定银行卡吗？

不需要。真正免费的网站不会要卡号。如果“免费”注册却要求填卡，多半是会自动续费扣款的试用。
