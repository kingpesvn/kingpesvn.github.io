免费制作网站：5 分钟做好店铺网站的 7 个步骤

不用写代码，跟着 7 个步骤为小店免费制作网站：选模板、加商品和价格、接订单、发布上线，全程零费用，第一版约 5 分钟完成。

你开着一家小店，希望顾客能在 Google 上找到你，却觉得做网站又贵又慢还要懂技术？其实只要一部手机或一台电脑，就能为店铺免费制作网站，第一版大约 5 分钟就能完成。本文从选模板到网站上线，一步步带你完成。

快速总结：为店铺免费制作网站的 7 个步骤

  1. 选择适合你行业的模板
  2. 修改店名、标志和颜色
  3. 添加商品、价格和实拍照片
  4. 设置联系方式和下单方式
  5. 免费发布网站
  6. 绑定自有域名（可选）
  7. 把网站送到顾客面前

1. 选择适合你行业的模板

最重要的一步，是选一个专为你的行业设计的现成模板。

每个行业需要的内容不同：面包店需要带价格的菜单，咖啡馆需要按杯型分的饮品表。图片：rawpixel（CC0）

行业模板已经包含顾客想看的内容：面包店模板有带价格的商品列表，咖啡馆模板有按杯型定价的菜单和营业时间，美容院模板有价目表和预约。你不用设计版面，只需替换内容。

打开免费网站模板库，按类别筛选，点预览在手机上查看真实效果。看中了就点使用模板。例如：面包店网站模板、咖啡馆模板、美容院模板。

2. 修改店名、标志和颜色

模板会在编辑器中打开，旁边就是实时预览。你改哪一栏，预览马上跟着变。

在内容标签中填写店名、一句简短介绍和首页大图。在外观标签中选择和招牌或标志相配的主色，还可以把按钮文字改成”预订蛋糕”之类。

小贴士：介绍要短，写清楚卖什么、在哪里，例如”每天早上新鲜出炉的蛋糕，上海市区配送”。访客一眼就懂，Google 也更容易理解你的网站。

3. 添加商品、价格和实拍照片

这是顾客看得最多的部分，值得认真做。

像货架价签一样清楚的价格，能让顾客不用询问就快速做决定。图片：rawpixel（CC0）

在商品标签中创建类别（如蛋糕、面包、饮品），再逐个添加商品的名称、价格和照片。用手机时，添加商品时可以直接用相机拍照。每件商品最好有 1–3 张光线充足的实拍照片。

商品多时，下载 .csv 表格文件，在 Excel 或 Google 表格里批量修改后再导入。如果卖到多个国家，每个国家都可以设置自己的价格和货币。

4. 设置联系方式和下单方式

只有顾客在想买的那一刻能马上联系你，网站才有用。

顾客看完马上就想问尺码和价格：下单按钮要放在最显眼的位置。图片：Artem Beliaikin（CC0）

在联系方式标签中填写电话、微信、地址（地图会按地址显示）和营业时间。想让订单更有条理，就开启通过 Google 表单接单：每个订单会成为 Google 表格中的一行，还可以开启新订单邮件提醒。

这个标签里还有外卖平台链接、临时休息通知、退换货政策和网站二维码。

5. 免费发布网站

预览满意后，点发布网站。选一个网站名称（会出现在网址中），然后用免费的 GitHub 账号登录。GitHub 负责存放和运行你的网站，自带 HTTPS（浏览器地址栏的小锁）。

大约 1–2 分钟后，网站就会 24 小时在线。网站在你自己的账号里，所有权属于你。要修改时，重新打开编辑器，改完点更新网站即可。

暂时不想注册账号？也可以把网站下载成 .zip 文件保存，之后再发布。

6. 绑定自有域名（可选）

免费地址类似 账号名.github.io/店名，马上就能用。想要印在招牌上的短地址，比如 yourshop.com，可以在域名商处购买域名（通常按年付费），再在发布窗口选择自有域名。

编辑器会列出需要在域名商处添加的 DNS 记录，附带复制按钮和检查域名按钮。指向正确后，HTTPS 会自动开启。除了域名费用，没有其他费用。

7. 把网站送到顾客面前

网站做好了，顾客不会自己找上门。要把它放到顾客接触你的每一个地方。

就像门口的黑板一样，网站也要经常更新新品、价格和优惠。图片：pixellaphoto（CC0）

  • 打印网站二维码（在联系方式标签下载），贴在收银台、餐桌和包装袋上。
  • 在地图上加链接：通过 Google 商家资料，让搜索”附近的面包店”的人也能看到你的网站；国内顾客也可以在大众点评、高德地图的店铺资料里放上链接。
  • 把链接放到小红书、微信、抖音，以及消息签名里。
  • 经常更新：新品、新价格、节假日营业时间。新鲜的信息能赢得信任。

免费网站有哪些限制？

说清楚，方便你做选择：

  • 暂时没有在线支付和购物车。 顾客通过电话、微信或 Google 表单下单，你照常确认并收款。
  • 发布需要 GitHub 账号。 免费，几分钟就能注册，登录页面就有注册按钮。
  • 有了网站不代表马上排在 Google 前列。 需要时间、清楚的内容和持续更新。

如果店铺需要购物车、在线支付或独立服务器，请看高级方案。如果你只需要一个好看的网站，让顾客能找到你、看商品、下订单，免费版就足够了。

现在就开始：打开 Kingpes 首页，在搜索框输入你的行业，选一个模板。第一版大约 5 分钟就能完成。

常见问题

免费制作网站真的不花钱吗？

模板、编辑器、网站地址和 HTTPS 都免费。只有想用 yourshop.com 这样的自有域名时，才需要按年向域名商付费。

不会写代码也能做网站吗？

可以。只需在现成的栏位里填文字、换照片和价格，设计和手机显示模板都已做好。

免费网站能接订单吗？

能。顾客可以打电话、发微信，或填写 Google 表单，订单会进入你的 Google 表格。暂时还没有在线支付。

发布网站需要什么账号？

一个免费的 GitHub 账号，用来存放和运行网站。如果暂时不想注册，可以把网站下载成 .zip 文件。
