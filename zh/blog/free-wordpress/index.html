WordPress免费建站：小店值得用吗？

WordPress免费建站真的免费吗？讲清 WordPress.com 与 .org 的区别、隐藏费用、日常维护，以及小店何时该选更轻的方案。

1. WordPress.com 和 WordPress.org 有什么区别？

WordPress 是开源建站软件，驱动着全球大量网站。用法有两种：WordPress.com 是注册即用的托管服务；WordPress.org 是下载软件，安装到你自己的主机上。

选择之前，先列出网站要做什么：卖货、预约，还是只做介绍。图片：Glenn Carstens-Peters（CC0）

两者在费用和工作量上差别很大，所以“WordPress 免费”往往只说对了一半。

2. WordPress.com 免费方案有哪些限制？

免费方案给你 yourshop.wordpress.com 这样的地址。按撰文时的价格表，通常会显示平台广告、不能绑定自己的域名、也不能安装网店等额外插件。

想去广告、用自己的域名或正经卖货，就要升级按年付费的方案。方案会变动，请查看最新价格。

3. 自建 WordPress：软件免费，运行花钱

从 WordPress.org 自建拥有完全控制权，但要付主机和域名费。视服务商而定，主机每月从几十到几百元人民币不等，域名按年计费。很多好看的主题和网店插件也要付费。

WordPress 像一整套工具箱：能做很多事，但每样工具都要会用。图片：Todd Quackenbush（CC0）

还有时间成本：选主题、装插件、调手机版、接支付。新手可能要花几天，或者得请人做。总费用可参考网店网站要花多少钱。

4. 维护：更新、安全、备份

WordPress 网站需要持续照料。核心、主题和插件经常发布更新，长期不更新更容易被攻击。

定期更新和备份，就是给 WordPress 网站锁好门。图片：Mx. Granger（CC0）

每月要做：更新、检查插件是否兼容、备份数据、检查速度。没时间的话，就得额外付费请人维护。

5. 什么时候该用 WordPress？

需要大量文章的博客、多位作者，或会员、库存对接等定制功能时，选 WordPress，维护的投入是值得的。

如果只是让顾客看商品和价格、预约、发订单，就不必用。刚起步的小店通常想今天就有网站，而不是先学主机管理。

小店更轻的选择

按行业设计的模板已含卖货或预约功能，不用管理插件和更新。比如家教中心模板有学费计算和免费试听报名，游戏机商店模板有购物袋和旧机估价。

步骤见免费制作网站指南，也可以对比用Canva做网站和 Google 协作平台，或在模板库挑选设计。

常见问题

WordPress 真的免费吗？

WordPress 软件免费，但运行需要主机和域名，通常要付费；WordPress.com 的免费方案有限制和广告。

不会写代码能用 WordPress 吗？

可以用区块编辑器搭建，但安装、选插件、更新和排查错误仍需要一些技术知识或他人帮忙。

WordPress 网站容易被攻击吗？

用的人多，所以常被扫描。定期更新、用可靠插件、经常备份能大幅降低风险；长期不管才是问题。

刚起步的小店该选什么？

如果只需顾客看商品、看价格并发订单，现成模板通常更快更轻。WordPress 适合大型博客或定制功能。
