Đăng website lên mạng

  1. 1Chọn địa chỉ

  2. 2Kết nối GitHub

    Website được lưu miễn phí trong tài khoản GitHub của chính bạn. Bạn là chủ sở hữu: Kingpes không giữ website hay dữ liệu của bạn.

    Đã có tài khoản GitHub
    Chưa có tài khoản? Đăng ký miễn phí khoảng 2 phút
    1. 1
      Mở trang đăng ký GitHub

      Trang mở ở tab mới. Bản nháp vẫn nằm ở tab này, không mất.

      Mở trang đăng ký ↗
    2. 2
      Nhập email, mật khẩu và tên người dùng

      Tên người dùng sẽ nằm trong địa chỉ website (ten-tai-khoan.github.io), nên chọn tên ngắn giống tên cửa hàng. GitHub có thể hỏi một câu đố nhỏ để xác minh bạn là người thật.

    3. 3
      Xác nhận email

      Mở email, nhập mã GitHub vừa gửi. Xong thì quay lại tab này và bấm "Đăng nhập bằng GitHub".

    GitHub dùng tiếng Anh: Username = tên người dùng · Password = mật khẩu · Continue = tiếp tục · Create account = tạo tài khoản.

    Phần kết nối GitHub đang được hoàn thiện. Bản nháp của bạn đã lưu trên trình duyệt này. Trong lúc chờ, bạn có thể tải bản website về máy.
