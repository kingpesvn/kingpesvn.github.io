  1. 1Chọn địa chỉ

    Trỏ tên miền về website

    Vào trang quản lý tên miền (nơi bạn đã mua), mục DNS, thêm các bản ghi dưới đây. Bản ghi cũ trùng tên thì xóa đi.

    LoạiTênGiá trị

    Đổi DNS có thể mất từ vài phút đến 24 giờ. Trỏ đúng rồi, GitHub tự bật HTTPS (ổ khóa) trong khoảng 1 giờ.

  2. 2Kết nối GitHub

    Website được lưu miễn phí trong tài khoản GitHub của chính bạn. Bạn là chủ sở hữu: Kingpes không giữ website hay dữ liệu của bạn.

    Phần kết nối GitHub đang được hoàn thiện. Bản nháp của bạn đã lưu trên trình duyệt này. Trong lúc chờ, bạn có thể tải bản website về máy.
