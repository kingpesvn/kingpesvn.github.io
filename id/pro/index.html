Pertanyaan tentang paket lanjutan

Apa bedanya dengan paket gratis?

Paket gratis adalah situs profil yang menerima pesanan lewat chat atau telepon. Paket lanjutan menambahkan keranjang, pembayaran online, manajemen pesanan, dan kode sumber lengkap untuk Anda jalankan sendiri.

Server seperti apa yang dibutuhkan?

VPS Linux standar sudah cukup untuk toko kecil dan menengah. Situs berjalan di Docker, jadi instalasinya hanya beberapa perintah.

Apakah data situs gratis bisa dipindahkan?

Bisa. Produk, harga per negara, dan konten diimpor langsung tanpa mengetik ulang.

Minta penawaran paket lanjutan

Tinggalkan kontak Anda, kami kirim penawaran dalam 1–2 hari kerja.
