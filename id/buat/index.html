Tayangkan situs Anda

  1. 1Pilih alamat

    Arahkan domain ke website

    Buka dasbor penyedia domain (tempat Anda membeli), masuk ke DNS, lalu tambahkan record di bawah. Hapus record lama dengan nama yang sama.

    TipeNamaNilai

    Perubahan DNS bisa butuh beberapa menit hingga 24 jam. Setelah benar, GitHub menyalakan HTTPS (ikon gembok) dalam sekitar 1 jam.

  2. 2Hubungkan GitHub

    Situs Anda disimpan gratis di akun GitHub milik Anda sendiri. Anda pemiliknya: Kingpes tidak menyimpan situs atau data Anda.

    Koneksi ke GitHub masih disempurnakan. Draf Anda sudah tersimpan di browser ini. Sementara itu, Anda bisa mengunduh situsnya.
