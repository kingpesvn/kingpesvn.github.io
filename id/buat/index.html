    Situs Anda disimpan gratis di akun GitHub milik Anda sendiri. Anda pemiliknya: Kingpes tidak menyimpan situs atau data Anda.

    Saya punya akun GitHub
    Belum punya akun? Daftar gratis sekitar 2 menit
    1. 1
      Buka halaman daftar GitHub

      Terbuka di tab baru. Draf tetap ada di tab ini.

      Buka halaman daftar ↗
    2. 2
      Isi email, kata sandi, dan nama pengguna

      Nama pengguna menjadi bagian alamat situs (akun-anda.github.io), jadi pilih yang pendek seperti nama toko. GitHub mungkin meminta teka-teki kecil untuk memastikan Anda manusia.

    3. 3
      Konfirmasi email

      Buka email dan masukkan kode dari GitHub. Lalu kembali ke tab ini dan klik "Masuk dengan GitHub".

    Tampilan GitHub berbahasa Inggris: Username = nama pengguna · Password = kata sandi · Continue = lanjut · Create account = buat akun.

    Koneksi ke GitHub masih disempurnakan. Draf Anda sudah tersimpan di browser ini. Sementara itu, Anda bisa mengunduh situsnya.
