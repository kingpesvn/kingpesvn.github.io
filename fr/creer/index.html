Mettre votre site en ligne

  1. 1Choisir une adresse

  2. 2Connecter GitHub

    Votre site est enregistré gratuitement dans votre propre compte GitHub. Vous en êtes propriétaire : Kingpes ne conserve ni votre site ni vos données.

    J’ai un compte GitHub
    Pas encore de compte ? Inscription gratuite en 2 minutes environ
    1. 1
      Ouvrez la page d’inscription GitHub

      Elle s’ouvre dans un nouvel onglet. Votre brouillon reste dans cet onglet.

      Ouvrir l’inscription ↗
    2. 2
      Saisissez un e-mail, un mot de passe et un nom d’utilisateur

      Le nom d’utilisateur fait partie de l’adresse (votre-compte.github.io) : choisissez un nom court, proche de celui de votre commerce. GitHub peut vous demander un petit puzzle pour vérifier que vous êtes humain.

    3. 3
      Confirmez votre e-mail

      Ouvrez votre messagerie et saisissez le code envoyé par GitHub. Revenez ensuite sur cet onglet et cliquez sur « Se connecter avec GitHub ».

    GitHub est en anglais : Username = nom d’utilisateur · Password = mot de passe · Continue = continuer · Create account = créer un compte.

    La connexion à GitHub est en cours de finalisation. Votre brouillon est enregistré dans ce navigateur. En attendant, vous pouvez télécharger votre site.
