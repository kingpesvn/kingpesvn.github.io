Mettre votre site en ligne

  1. 1Choisir une adresse

    Faire pointer votre domaine vers le site

    Ouvrez l’espace client de votre fournisseur de domaine (là où vous l’avez acheté), section DNS, et ajoutez les enregistrements ci-dessous. Supprimez les anciens enregistrements de même nom.

    TypeNomValeur

    Un changement DNS prend de quelques minutes à 24 heures. Une fois le domaine bien pointé, GitHub active le HTTPS (cadenas) en une heure environ.

  2. 2Connecter GitHub

    Votre site est enregistré gratuitement dans votre propre compte GitHub. Vous en êtes propriétaire : Kingpes ne conserve ni votre site ni vos données.

    La connexion à GitHub est en cours de finalisation. Votre brouillon est enregistré dans ce navigateur. En attendant, vous pouvez télécharger votre site.
