QR code pour commerce : 6 usages au-delà du menu

Un QR code pour commerce ne sert pas qu'au menu : 6 usages comme votre site, les avis Google, WhatsApp, le Wi-Fi, le paiement et la recommande, avec des conseils.

Par Kingpes · Publié 15 octobre 2026 · 5 min de lecture

Beaucoup de commerces utilisent déjà un QR code pour afficher la carte. Mais un QR code pour commerce peut faire bien plus : aider le client à garder vos coordonnées, laisser un avis, vous écrire, payer vite et revenir acheter. Cet article rassemble 6 usages du QR code au-delà du menu, pour boulangeries, bars à bubble tea, fleuristes, boutiques de mode et instituts, avec des conseils d’impression pour qu’il se scanne du premier coup.

En bref, 6 usages du QR code au-delà du menu :

  1. Ouvrir le site de la boutique
  2. Demander des avis Google
  3. Écrire sur WhatsApp ou suivre votre compte
  4. Se connecter au Wi-Fi sans dicter le mot de passe
  5. Payer depuis le téléphone
  6. Recommander depuis le sac, le ticket ou l’emballage

1. Ouvrir le site de la boutique

C’est le QR code le plus utile. Un seul code ouvre le site de votre boutique, avec les produits, les prix, les horaires, l’adresse et un bouton de commande.

  • Sur la vitrine : les passants peuvent scanner et commander même quand c’est fermé.
  • Au comptoir : les clients qui attendent découvrent d’autres produits.
  • Sur les cartes de visite, flyers et kakémonos des marchés et salons.

Le QR code doit mener à votre site, pas à une publication sur les réseaux ni à une image. Les publications disparaissent dans le fil et les images ne se modifient pas, alors que le site se met à jour autant de fois que vous voulez sans changer le code. Si vous n’utilisez le QR code que pour la carte, voyez aussi comment créer un menu QR code pour un café.

2. Demander des avis Google

Les avis sur Google Maps rassurent les nouveaux clients et aident votre boutique à apparaître quand on cherche à proximité. Le problème : les clients satisfaits oublient souvent d’en écrire.

Un QR code qui ouvre directement la fenêtre d’avis règle ça. Récupérez le lien dans votre fiche d’établissement Google (« Demander des avis » ou « Partager le formulaire d’avis » ; voir l’aide Google), puis créez un QR code avec ce lien.

  • Placez-le à la caisse ou sur les tables, avec une phrase courte : « Satisfait ? Scannez pour nous laisser un avis ».
  • N’offrez rien en échange de 5 étoiles ; demandez simplement un avis sincère.

Pas encore sur Google Maps ? Voyez comment ajouter votre commerce sur Google Maps.

3. Écrire sur WhatsApp ou suivre votre compte

Le client achète une fois et repart, et vous n’avez aucun moyen de le prévenir des nouveautés ou des offres. Un QR code pour écrire sur votre WhatsApp Business ou suivre votre Instagram garde ce lien.

  • Annoncez l’avantage : « Ajoutez-nous sur WhatsApp pour savoir chaque matin ce qui sort du four » ou « Suivez-nous pour connaître les arrivages ».
  • Placez-le là où le client attend : le comptoir des boissons, la table d’emballage cadeau, la salle d’attente de l’institut.

4. Se connecter au Wi-Fi sans dicter le mot de passe

Cafés, bars à bubble tea et instituts entendent « c’est quoi le code Wi-Fi ? » cent fois par jour. Un QR code Wi-Fi permet de scanner et se connecter, sans rien taper.

  • Beaucoup d’outils gratuits ont une option « Wi-Fi » : saisissez le nom du réseau et le mot de passe, c’est fait.
  • Utilisez un réseau invité séparé de celui de la caisse.
  • Si vous changez le mot de passe, pensez à réimprimer le code.

Sous le code Wi-Fi, ajoutez une ligne : « Voir la carte et commander sur… » avec le QR code de votre site. Le client qui vient de se connecter la consulte tout de suite.

5. Payer depuis le téléphone

Un QR code de paiement permet au client de payer vite, sans que vous dictiez un IBAN ni craigniez une faute de frappe.

Un QR code de paiement près de la caisse fluidifie l’encaissement aux heures de pointe. Photo : StockSnap (CC0).

  • Obtenez le QR code de paiement de votre banque ou de votre solution d’encaissement (par exemple Wero, Lydia Pro ou SumUp, selon ce que vous utilisez), imprimez-le et posez-le à la caisse.
  • Indiquez le nom du bénéficiaire sous le code pour que le client vérifie avant de payer.
  • Vérifiez que l’argent est bien arrivé avant de remettre la commande ; méfiez-vous des fausses captures de paiement.
  • Sur votre site, vous pouvez afficher les moyens de paiement sur la page de commande pour les clients qui réservent.

6. Recommander depuis le sac, le ticket ou l’emballage

Un client satisfait est celui qui revient le plus facilement. Placez un QR code là où il le verra une fois rentré chez lui :

Un QR code imprimé sur le sac ou un autocollant rentre à la maison avec le client. Photo : rawpixel (CC0).

  • Sacs, boîtes à gâteaux, autocollants : « Scannez pour recommander » mène à la page produit de votre site.
  • Tickets et cartes de garantie : mènent au mode d’emploi, à la garantie ou à la politique de retour.
  • Cartes glissées dans un bouquet ou un cadeau : mènent à une page de remerciement avec une réduction pour la prochaine fois.

7. Conseils pour un QR code facile à scanner

Un QR code mal imprimé fait échouer le client plusieurs fois, puis il abandonne. Avant d’imprimer :

  • Taille : à partir d’environ 2 × 2 cm pour une étiquette lue de près ; bien plus grand en vitrine.
  • Contraste : code foncé sur fond clair, marge blanche autour, jamais sur une photo chargée.
  • Une consigne juste en dessous : à quoi sert le scan.
  • Testez avec plusieurs téléphones différents, y compris dans la pénombre.
  • Visez une page fixe de votre site, pour changer le contenu sans réimprimer.

Questions fréquentes

Créer un QR code est-il payant ?

Un QR code qui mène à un lien se crée gratuitement avec de nombreux outils en ligne, ou directement dans Chrome (Partager, puis « Créer un code QR »). Un QR code de paiement s'obtient auprès de votre banque ou de votre solution d'encaissement.

Si je change le contenu, dois-je réimprimer le QR code ?

Si le QR code mène à votre site, il suffit de modifier le site et l'ancien code reste valable. C'est pourquoi il vaut mieux viser une page fixe plutôt qu'un fichier image ou une publication sur les réseaux.

Quelle taille minimale pour un QR code ?

À titre indicatif, environ 2 × 2 cm ou plus pour une étiquette lue de près, et beaucoup plus grand pour une vitrophanie lue de loin. Testez toujours avec plusieurs téléphones avant d'imprimer en quantité.

Un seul QR code pour tout, c'est une bonne idée ?

Mieux vaut un code par usage. Celui de la caisse sert au paiement, celui du sac à recommander sur le site, celui de l'entrée à laisser un avis. Quand le client sait à quoi sert le code, il le scanne.
