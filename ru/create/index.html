    У меня есть аккаунт GitHub
    Нет аккаунта? Бесплатная регистрация займёт около 2 минут
    1. 1
      Откройте страницу регистрации GitHub

      Она откроется в новой вкладке. Черновик останется в этой вкладке.

      Открыть регистрацию ↗
    2. 2
      Укажите почту, пароль и имя пользователя

      Имя пользователя станет частью адреса (your-account.github.io), поэтому выберите короткое, похожее на название магазина. GitHub может попросить решить небольшую головоломку, чтобы убедиться, что вы человек.

    3. 3
      Подтвердите почту

      Откройте письмо и введите код от GitHub. Затем вернитесь в эту вкладку и нажмите «Войти через GitHub».

    GitHub на английском: Username = имя пользователя · Password = пароль · Continue = продолжить · Create account = создать аккаунт.

    Подключение к GitHub ещё дорабатывается. Черновик сохранён в этом браузере. Пока можно скачать сайт.
