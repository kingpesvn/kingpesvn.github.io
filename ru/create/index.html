Опубликовать сайт

  1. 1Выберите адрес

    Направьте домен на сайт

    Откройте панель регистратора домена (где вы его купили), раздел DNS, и добавьте записи ниже. Старые записи с тем же именем удалите.

    ТипИмяЗначение

    Изменения DNS занимают от нескольких минут до 24 часов. Когда домен настроен верно, GitHub включит HTTPS (замок) примерно в течение часа.

  2. 2Подключите GitHub

    Сайт бесплатно хранится в вашем собственном аккаунте GitHub. Он принадлежит вам: Kingpes не хранит ваш сайт и ваши данные.

    Подключение к GitHub ещё дорабатывается. Черновик сохранён в этом браузере. Пока можно скачать сайт.
