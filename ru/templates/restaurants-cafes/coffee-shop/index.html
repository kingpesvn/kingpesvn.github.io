О шаблоне

Бесплатный шаблон сайта для кофейни: меню в стиле грифельной доски, цены по объёму, фирменные напитки, фото зала и уголок продажи обжаренного зерна. Тёплая тёмная палитра подходит спешелти-кофейням и кафе-библиотекам.

Есть часы работы, карта, ссылки на сервисы доставки, отзывы гостей и QR-код, который сканируют за столиком, чтобы открыть меню. Напитки, цены, фото и цвета меняются за минуты, без кода. С этим шаблоном можно создать сайт бесплатно и опубликовать его примерно за 5 минут.

Частые вопросы

Можно ли использовать как QR-меню?

Да. В шаблоне есть QR-код, открывающий сайт: скачайте, распечатайте и поставьте на столы.

Как указать цены для малого, среднего и большого объёма?

У каждого напитка есть цена для каждого объёма — правится в разделе «Товары».

Можно добавить ссылки на доставку?

Да. Во вкладке «Контакты» есть раздел для ссылок на сервисы доставки.
