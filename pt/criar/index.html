    Já tenho conta no GitHub
    Ainda não tem conta? Cadastre-se grátis em cerca de 2 minutos
    1. 1
      Abra a página de cadastro do GitHub

      Ela abre em uma nova aba. Seu rascunho continua nesta aba.

      Abrir cadastro ↗
    2. 2
      Informe e-mail, senha e nome de usuário

      O nome de usuário faz parte do endereço (sua-conta.github.io), então escolha algo curto, como o nome da loja. O GitHub pode pedir um pequeno quebra-cabeça para confirmar que você é uma pessoa.

    3. 3
      Confirme seu e-mail

      Abra seu e-mail e digite o código enviado pelo GitHub. Depois volte para esta aba e clique em "Entrar com o GitHub".

    O GitHub está em inglês: Username = nome de usuário · Password = senha · Continue = continuar · Create account = criar conta.
